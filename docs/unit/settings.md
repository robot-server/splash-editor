# 유닛 설정 — 유즈맵의 98%가 고친다

`unitdef set` (CHK 의 `UNIS`·`UNIx`) 은 **맵마다 유닛 능력치를 새로
정하는 자리**다. 내 맵은 여태 하나도 안 고쳤다. 실측은 반대다.

실측: 유즈맵 **479장** 전수. `measure_unitdefs.py` ·
[data/unitdefs.json](../../.agents/skills/starcraft-map/data/unitdefs.json).

| | 값 |
| --- | --- |
| 유닛 설정을 **고치는 맵** | **473장 / 479장 = 98%** |
| 고치는 유닛 **종류 수** | 중앙 **90종** |
| 가장 많이 건드리는 칸 | 체력 > 생산시간 > 미네랄 > 방어력 > 가스 > 방패 |

> 유즈맵은 "스타크래프트 유닛으로 노는 맵" 이 아니다. **유닛을 다시
> 정의한 맵**이다. 마린 체력 40 을 그대로 두고 만든 유즈맵은 거의 없다.

## 가장 자주 고치는 유닛

중앙값이지 정답은 아니다. 값의 크기보다 **무엇을 고치는지**를 본다.

| 유닛 | 고친 맵 | 체력 중앙 | 미네랄 중앙 |
| --- | ---: | ---: | ---: |
| Terran Marine | 417 | 250 | 50 |
| Terran Ghost | 403 | 400 | 25 |
| Zerg Hydralisk | 401 | 200 | 75 |
| Zerg Zergling | 396 | 120 | 50 |
| Jim Raynor (Marine) | 390 | 1112 | 50 |
| Terran Firebat | 390 | 420 | 50 |
| Protoss Zealot | 370 | 275 | 100 |
| Terran Goliath | 369 | 700 | 100 |
| Protoss Dragoon | 368 | 400 | 125 |
| Terran Siege Tank (Tank) | 367 | 699 | 150 |
| Hunter Killer (Hydralisk) | 367 | 800 | 150 |
| Terran Civilian | 366 | 40 | 0 |

마린 체력이 **원래 40인데 중앙값 250** 이다. 여섯 배다. 유즈맵은
유닛을 그대로 쓰지 않는다.

## 고칠 수 있는 것

출처: 스타 에디터 아카데미
[[기초6] 유닛/업그레이드/기술 설정](https://cafe.naver.com/edac/book5095361/76373).

```sh
splash-cli unitdef set 맵 "Terran Marine" \
    --default off --hp 250 --minerals 50 --build-time 120 --in-place
```

| 칸 | 뜻 | 최댓값 |
| --- | --- | ---: |
| `--hp` | 체력. **표시값**으로 적는다 (안에서 ×256) | **8,388,607** (2²³−1) |
| `--shields` | 방패. 방패 없는 유닛엔 넣어도 소용없다 | 65,535 |
| `--armor` | 방어력 | **255** |
| `--build-time` | 생산 시간 | 65,535 |
| `--minerals` · `--gas` | 값 | 각 65,535 |
| (에디터만) 이름 | `Custom Names` | 스트링 |
| (에디터만) 공격력 | 기본 + 업그레이드당 증가 | 합쳐 65,535 |
| (에디터만) 생산 가능 여부 | 플레이어별로 따로 정할 수 있다 | — |

**`--default off` 를 빼면 아무 일도 안 일어난다.** "기본값 따름" 칸이
켜져 있으면 나머지 값을 적어도 게임이 안 본다.

### 함정

| | |
| --- | --- |
| **건물의 최대 체력을 0 으로 두면** | **튕긴다** |
| 체력 **167,772 이상**인 유닛·건물을 맵에 **배치해 두면** | 빨피 상태가 되고 값이 제대로 안 먹는다 |
| 생산 시간에 비해 체력이 많으면 | 생산될 때 **빨피로** 나온다 |
| 공격력이 65,535 를 넘으면 | **오버플로우**로 0 부터 다시 센다 (50000 + 20000 = 4464) |
| 밀리맵으로 실행하면 | **유닛 설정이 통째로 안 먹는다** |

체력 칸 옆의 작은 칸은 **가분수 체력**이다. `40, 5` 로 넣으면 마린이
`45/40` 으로 시작한다. 작은 칸에는 **9 까지** 넣을 수 있다 (카페 댓글).

### 생산 시간의 자가 다르다

| | 1 이 뜻하는 것 |
| --- | --- |
| 유닛 생산 시간 | **실제 0.042초.** 24 ≒ 1초 (에디터의 "15 = 1초" 는 노말 기준) |
| 업그레이드 · 기술 시간 | **노말 기준 1초.** 실제로는 약 42/67초 |

→ [../game/time.md](../game/time.md)

### 공격력은 유닛이 아니라 **무기**에 붙는다

> 마린은 그 무기를 쓸 뿐이다.

그래서 **무기를 나눠 쓰는 유닛은 따로 정할 수 없다.** 카페가 노라드II ·
멩스크 · 듀갈을 예로 든다 — 내가 잰 것과 같다
([heroes.md](heroes.md)). 타사다르(템플러)와 알다리스(템플러)도 그렇다.

**dat 의 피해 값이 게임 표기와 다를 수 있다.** 골리앗은 미사일이
2발이라 10 짜리가 20 으로 보인다.

두 배로 보이는 것은 `weapons.dat` 의 **투사체 수**다 (`damageFactor`).
골리앗 포탑은 공중 10 × 2 = 20 이다. `units.dat` 의 "타격 수" 칸은
**적용되지 않으니** 그 값을 곱하면 안 된다 →
[damage.md](damage.md).

## 업그레이드와 기술도 맵이 정한다

`splash-cli upgrade set` · `tech set`.

| 업그레이드 | |
| --- | --- |
| 비용 (미네랄 · 가스 · 시간) | 각 65,535 |
| `Upgrade Factor` | 단계마다 오르는 값 |
| `Initial Level` | **시작할 때 이미 되어 있는 단계** (최대 255) |
| `Max Level` | 올릴 수 있는 끝 (최대 255) |

| 기술 | |
| --- | --- |
| 미네랄 · 가스 · 시간 | 각 65,535 |
| `Energy` | 쓸 때 드는 에너지 (최대 255) |

> 일부 기술은 **에너지 설정이 안 먹는다** — 시즈 모드, 커맨드 센터
> 감염 등.

유닛 · 업그레이드 · 기술 모두 **플레이어별로 따로** 정할 수 있다.
기본을 Disabled 로 두고 한 플레이어만 Enabled 로 하는 식이다 —
유즈맵에서 "이 편만 뽑을 수 있는 유닛" 을 만드는 방법이다.

## 고를 때 묻는 것

1. 이 맵에서 플레이어가 **오래 살아야 하는가**? → 체력
2. **자주 사야 하는가**? → 미네랄·생산시간을 낮춘다
3. **단단함이 중요한가**? → 방어력. **공격 형태를 곱하기 전에** 빠지므로
   체력보다 세게 먹는다 ([damage.md](damage.md))
4. 사거리·속도가 중요한가? → **여기서는 못 한다.** 유닛을 바꾼다
