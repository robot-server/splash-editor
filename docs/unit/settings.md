# [유닛 설정 메커니즘]

## 역할 이름·능력치·무기를 하나의 유닛 프로필로 설정

- 메커니즘 이름: 유닛 역할 프로필의 명시적 편집
- 적용 이유/목적: 유즈맵에서 바닐라 유닛을 다른 역할로 쓸 때 체력만 바꾸거나 설정 기본값을 꺼 놓고 이름·무기 피해를 빠뜨리는 부분 적용을 방지한다.
- 구체적 규칙 (설정 항목 및 적용 방식): 스타 에디터 아카데미의 [유닛/업그레이드/기술 설정 강좌](https://cafe.naver.com/edac/book5095361/76373)는 `Use Defaults`를 해제해야 해당 유닛 설정 항목을 편집할 수 있고, `Custom Names`를 해제해야 이름을 바꿀 수 있다고 설명한다. 맵의 UNIS/UNIx 설정으로 이름, 체력, 방패, 방어력, 생산 시간, 자원 비용, 플레이어별 생산 허용을 설정할 수 있다. 지상/공중 무기 피해와 업그레이드당 증가는 역할을 정할 때 확인하되, 맵의 일반 유닛 설정 편집 항목으로 바꿀 수 있다고 안내하지 않는다. 변경할 설정을 목록화하고, 저장 뒤 해당 플레이어의 게임에서 실제 이름·양쪽 공격 대상·생존·생산 가능 여부를 검증한다.
- 잘된 예시 및 실패하는 나쁜 예시: 역할을 “방어용 근접 유닛”으로 정하면 화면 이름, 체력/방어, 실제 지상 무기, 생산 가능 플레이어가 그 역할과 일치하는 것이 성공이다. `Use Defaults`만 끄고 HP만 변경해 사용자 지정 이름과 공격력을 빠뜨리는 것은 불완전한 설정이다. 강좌는 무기 데이터가 공유될 수 있음을 예로 든다. 공유 무기를 바꾸면 같은 무기 정의를 참조하는 다른 유닛에도 영향이 가는지 해당 데이터에서 확인한다.

# [에디터 타일/배치 제약사항]

## 사용자 지정 유닛을 실제 생성·배치로 확인

- 지형 간 연결 규칙: 이 문서는 지형 연결 규칙을 다루지 않는다. 지상 유닛을 실제 배치하는 경우에만 생성 지점에서 이동할 보행 공간을 별도로 검사한다.
- 유닛 길막/동선 보장 규칙: 유닛 설정이 올바르게 저장됐는지 이름·피해·설정이 적용되는 게임 모드에서 확인한다. 강좌는 밀리 모드와 유즈맵 모드의 설정 적용 차이를 지적하므로, 유즈맵 유닛 설정을 밀리 모드 시험 결과로 판정하지 않는다.

출처: [스타 에디터 아카데미 강좌 76373](https://cafe.naver.com/edac/book5095361/76373), [유닛 속성 설정하기](https://cafe.naver.com/edac/book1678930/19812). 수치 표본의 분포를 설계 기본값으로 사용하지 않는다.
