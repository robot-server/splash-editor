# 유닛별 예외 — **게임에 박혀 있어 dat 으로는 못 고친다**

유닛 번호(unit type)에 딸린 예외들이다. 능력치가 아니라 **동작**이라
`units.dat` 에도 `unitdef set` 에도 없다. 유즈맵을 짜다 "왜 안 되지" 로
막히는 자리가 거의 여기다.

출처: 스타 에디터 아카데미
[[팁] 유닛별 고유 특성들 (exe 영역)](https://cafe.naver.com/edac/book5095361/88226)
(댓글 포함) + 실측.

> **"~류" 는 영웅까지 포함**이다. 고스트류 = 일반 고스트 · 사라 케리건
> (고스트) · 사미르 듀란(고스트) · 알렉세이 스투코프(고스트) · 감염된
> 듀란.

## 튕긴다 — 먼저 볼 것

| 하면 | 무슨 일 |
| --- | --- |
| **고스트류에 "단일 개체" 를 켜 두고** 그 고스트가 죽거나 `Remove` 되면 | **게임이 튕긴다** |
| **미네랄 필드 1·2·3, 베스핀 간헐천을 유닛화**하면 | **튕긴다** |

→ [../game/crashes.md](../game/crashes.md) 에도 옮겨 적었다.

## 트리거가 안 먹는 유닛

유즈맵 판정의 97%가 `Bring` 이다. 그런데 **안 걸리는 유닛이 있다.**

| 유닛 | 안 되는 것 |
| --- | --- |
| **맵 리빌러** | **로케이션 인식이 통째로 안 된다** — `Bring` 조건도, `Remove Unit At Location` 도. `Remove Unit` 은 된다 |
| 맵 리빌러 · Door류 | `Give Units` 가 안 먹는다 |
| 트랩류 | `Move Location` 이 안 먹는다 |
| **스캐럽 · 인터셉터** | **트리거로 생성이 안 된다** |

맵 리빌러는 실측 유즈맵에서 가장 많이 놓는 유닛인데(디펜스 한 장에
11055기), **로케이션으로는 셀 수 없다.** 시야 여는 용도로만 쓴다.

## 클릭·선택이 안 되는 유닛

| | |
| --- | --- |
| 클릭 불가 | 핵 미사일 · 스캐너 스윕 · 스캐럽 · 다크 스웜 · 디스럽션 웹 · 맵 리빌러 · Door류 |
| 다중 선택 불가 | 크리터(동물류) · 스파이더 마인 |

## 자리를 안 가리고 생기는 유닛

| 유닛 | |
| --- | --- |
| **파워업류** | 생성 위치에 다른 유닛·건물이 있어도 **강제로 생긴다** |
| **비콘류** | 같다 (건설 크기 조건만 맞으면). 공중 유닛으로 바꿔도 강제로 생긴다 |

유즈맵에서 "무조건 여기 생겨야 하는 것" 이 있으면 이 둘을 쓴다.

## 영웅 유닛의 기본 업그레이드

> **영웅유닛류는 영웅 체크 여부와 관계없이 기본 업그레이드(속업 ·
> 사업 · 시야업)가 되어 있다. (벌처 영웅 같은 예외는 제외)**

`units.dat` 의 영웅 깃발을 꺼도 이 성질은 남는다는 뜻이다. 그리고
**짐 레이너(벌쳐)는 그 예외**라 속업이 안 되어 있다 — 이온 추진기를
올리면 일반 벌쳐와 함께 빨라진다. → [heroes.md](heroes.md)

## 공격·능력의 예외

| 유닛 | |
| --- | --- |
| 메딕 | **공격 명령을 내릴 수 없다** |
| **퀸류** | **체력 절반 미만의 커맨드 센터 말고는 공격을 못 한다.** 무기와 사거리를 설정해 줘도 안 된다 (감염 스크립트 때문) |
| 발키리 | 공중 공격이 **4회 쏘고 멈추는** 방식 (이미지 스크립트) |
| 스커지 | 사거리를 늘려도 첫 공격 뒤에는 **붙어서** 공격한다 |
| 스커지 · 감염된 테란 | **홀드시켜도 공격하지 않는다** |
| 리버 | **공격 속도를 보통 방법으로는 못 바꾼다** |
| 클로킹 | 원래 되는 유닛(고스트류 · 레이스류 · 케리건)만 된다. 발키리에 버튼을 줘도 안 된다 |
| 시즈 모드 | **시즈탱크류만** 된다 |
| 아비터 | 클로킹 범위 = **아비터의 공격 사거리** |
| 고스트류 | 핵 유도 사거리 = **고스트의 시야** |

## 생산 대기열

| | |
| --- | --- |
| 대기열로 유닛을 뽑을 수 있는 것 | **리버류 · 캐리어류뿐** |
| 저그 속성 건물 | **인페스티드 커맨드 센터 말고는** 대기열 생산이 안 된다 |
| 리버류 · 캐리어류 | 스캐럽 · 인터셉터 **아이콘을 없앨 수 없다** |

## 이름·계급이 고정되는 유닛

| 유닛 | |
| --- | --- |
| 히페리온 · 노라드 II | 유닛 이름을 바꾸면 계급이 **문자열 571번 "제독(Admiral)"** 으로 고정 |
| 간트리서 | 기본 이름을 쓰면 계급이 **문자열 572번 "태사다르"** 로 고정. 이름을 바꾸면 계급을 못 정한다 |
| 실드가 있는 유닛 | 실드 아이콘을 **없앨 수도 바꿀 수도 없다** |
| 시민(Civilian) | 계급을 보이게 할 수 없다 |

## 그 밖

- **라바와 비콘의 유닛 통과**는 유닛 고유 특성이다 (지형이 아니다).
- **가스 건물이 파괴되면 P12 소유의 베스핀 간헐천**이 생긴다.
  유즈맵에서 P12 유닛 수를 세고 있다면 어긋난다.
- 트랩류는 주변에 공격 대상이 없으면 **클로킹 상태**가 된다.
- **이그드라실을 다른 플레이어에게 기브하면 한 틱 늦게 발동한다**
  (카페 댓글).
