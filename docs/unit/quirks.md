# [트리거/로직 패턴]

## 유닛 고유 동작을 확인한 뒤 생성·이동 체인 구성

- 패턴 이름: 유닛 종류별 런타임 예외를 트리거 설계에 반영
- 구현하고자 하는 기능: 유닛 생성·이동·제거·선택을 쓰는 유즈맵 기능이 캔낫, 무반응, 크래시 없이 동작하게 한다.
- 조건(Condition) 및 액션(Action) 구조 체인: 유닛 종류를 정한 뒤 관련 예외를 확인한다. 생성은 `Create Unit`/`Create Unit with Properties`, 이동은 `Move Location`/`Move Unit`, 삭제는 `Remove Unit`/`Remove Unit At Location`, 판정은 `Bring`/`Command`를 사용하기 전에 이 페이지의 해당 유닛 제한을 대조한다. 동작하지 않는 액션에 의존하는 경우에는 대체 유닛이나 대상 명령으로 기능을 다시 구성한다.
- 예외 처리/버그 방지 로직: 스캐럽·인터셉터는 트리거 생성 대상이 아니다. 맵 리빌러는 로케이션 판정 대상이 아니며, 트랩류는 `Move Location`을 지원하지 않는다. 단일 개체 속성을 켠 고스트류를 죽이거나 제거하면 크래시가 날 수 있다. 미네랄 필드와 베스핀 간헐천은 유닛처럼 배치하지 않는다. 아래 표에서 언급되지 않은 상호작용은 대상 게임 버전에서 시험한다.

## 적용 목적과 근거

유닛 번호(unit type)에 붙은 동작은 `units.dat`나 `unitdef set`으로 바꿀 수
없는 경우가 있다. 아래 예외는 [유닛별 고유 특성 강좌](https://cafe.naver.com/edac/book5095361/88226)
및 런타임 재현에서 확인한 항목이다.

> **"~류" 는 영웅까지 포함**이다. 고스트류 = 일반 고스트 · 사라 케리건
> (고스트) · 사미르 듀란(고스트) · 알렉세이 스투코프(고스트) · 감염된
> 듀란.

## 튕긴다 — 먼저 볼 것

| 하면 | 무슨 일 |
| --- | --- |
| **고스트류에 "단일 개체" 를 켜 두고** 그 고스트가 죽거나 `Remove` 되면 | **게임이 튕긴다** |
| **미네랄 필드 1·2·3, 베스핀 간헐천을 유닛화**하면 | **튕긴다** |

→ [../game/crashes.md](../game/crashes.md) 에도 옮겨 적었다.

## 트리거가 안 먹는 유닛

`Bring` 조건과 로케이션 액션을 쓸 때 유닛별 동작 예외를 확인한다.

| 유닛 | 안 되는 것 |
| --- | --- |
| **맵 리빌러** | **로케이션 인식이 통째로 안 된다** — `Bring` 조건도, `Remove Unit At Location` 도. `Remove Unit` 은 된다 |
| 맵 리빌러 · Door류 | `Give Units` 가 안 먹는다 |
| 트랩류 | `Move Location` 이 안 먹는다 |
| **스캐럽 · 인터셉터** | **트리거로 생성이 안 된다** |

맵 리빌러는 로케이션 수량 판정에 사용하지 않고 시야 용도로만 쓴다.

### 일부만 지우려면 — 다 지우고 다시 만든다

`Remove Unit At Location` 이 안 먹으므로 **일부만 골라 지울 수 없다.**

> `Remove Unit` 으로 **맵 전체의 맵 리빌러를 없앤 다음**, 남겨 둘 자리에
> `Create Unit` 으로 **다시 만든다.**

### 자동 배치가 맵 밖으로 나간다

에디터의 "맵 전체에 맵 리빌러 깔기" 기능이 **맵 밖에 리빌러를 놓아
게임이 튕기는 일**이 있다. 좌측 목록에서 찾아 지운다
([../game/crashes.md](../game/crashes.md)).

플레이어마다 자리가 달라지므로, **P1 로 깔고 `Ctrl+A` → 엔터로 소유자를
바꾸는** 방법도 쓴다.

## 클릭·선택이 안 되는 유닛

| | |
| --- | --- |
| 클릭 불가 | 핵 미사일 · 스캐너 스윕 · 스캐럽 · 다크 스웜 · 디스럽션 웹 · 맵 리빌러 · Door류 |
| 다중 선택 불가 | 크리터(동물류) · 스파이더 마인 |

## 자리를 안 가리고 생기는 유닛

| 유닛 | |
| --- | --- |
| **파워업류** | 생성 위치에 다른 유닛·건물이 있어도 **강제로 생긴다** |
| **비콘류** | 같다 (건설 크기 조건만 맞으면). 공중 유닛으로 바꿔도 강제로 생긴다 |

유즈맵에서 "무조건 여기 생겨야 하는 것" 이 있으면 이 둘을 쓴다.

## 영웅 유닛의 기본 업그레이드

> **영웅유닛류는 영웅 체크 여부와 관계없이 기본 업그레이드(속업 ·
> 사업 · 시야업)가 되어 있다. (벌처 영웅 같은 예외는 제외)**

`units.dat` 의 영웅 깃발을 꺼도 이 성질은 남는다는 뜻이다. 그리고
**짐 레이너(벌쳐)는 그 예외**라 속업이 안 되어 있다 — 이온 추진기를
올리면 일반 벌쳐와 함께 빨라진다. → [heroes.md](heroes.md)

## 공격·능력의 예외

| 유닛 | |
| --- | --- |
| 메딕 | **공격 명령을 내릴 수 없다** |
| **퀸류** | **체력 절반 미만의 커맨드 센터 말고는 공격을 못 한다.** 무기와 사거리를 설정해 줘도 안 된다 (감염 스크립트 때문) |
| 발키리 | 공중 공격이 **4회 쏘고 멈추는** 방식 (이미지 스크립트) |
| 스커지 | 사거리를 늘려도 첫 공격 뒤에는 **붙어서** 공격한다 |
| 스커지 · 감염된 테란 | **홀드시켜도 공격하지 않는다** |
| 리버 | **공격 속도를 보통 방법으로는 못 바꾼다** |
| 클로킹 | 원래 되는 유닛(고스트류 · 레이스류 · 케리건)만 된다. 발키리에 버튼을 줘도 안 된다 |
| 시즈 모드 | **시즈탱크류만** 된다 |
| 아비터 | 클로킹 범위 = **아비터의 공격 사거리** |
| 고스트류 | 핵 유도 사거리 = **고스트의 시야** |

| 유닛 | |
| --- | --- |
| 히페리온 · 노라드 II | 유닛 이름을 바꾸면 계급이 **문자열 571번 "제독(Admiral)"** 으로 고정 |
| 간트리서 | 기본 이름을 쓰면 계급이 **문자열 572번 "태사다르"** 로 고정. 이름을 바꾸면 계급을 못 정한다 |

## 그 밖

- **라바와 비콘의 유닛 통과**는 유닛 고유 특성이다 (지형이 아니다).
- **가스 건물이 파괴되면 P12 소유의 베스핀 간헐천**이 생긴다.
  유즈맵에서 P12 유닛 수를 세고 있다면 어긋난다.
- 트랩류는 주변에 공격 대상이 없으면 **클로킹 상태**가 된다.
- **이그드라실을 다른 플레이어에게 기브하면 한 틱 늦게 발동한다**
  (카페 댓글).

## [에디터 타일/배치 제약사항]

- 지형 간 연결 규칙: 라바와 비콘은 유닛 통과 속성이므로 타일 자체의 walkability로 오인하지 않는다.
- 유닛 길막/동선 보장 규칙: 파워업류와 비콘류는 생성 시 겹치는 유닛·건물에 밀리지 않는 예외가 있다. 강제 생성 기능에 쓸 때는 일반 생성 유닛과 같은 충돌·자리 확보 규칙을 가정하지 말고, 생성 지점과 플레이 동선을 별도 시험한다.
