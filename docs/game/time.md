# 시간과 프레임 — **게임 시간은 실제 시간이 아니다**

출처: 스타 에디터 아카데미 [팁] 스타크래프트의 시간과 프레임
(`cafe.naver.com/edac/book5095361/76812`), [팁] 각종 타이머 지속시간
(`…/77409`). 별다른 말이 없으면 **Fastest 기준**이다.

## 기준

| | 값 |
| --- | --- |
| Fastest 한 프레임 | **0.042초** (1초에 약 24프레임) |
| Normal 한 프레임 | 0.067초 (1초에 약 15프레임) |
| Normal : Fastest | 42 : 67 ≒ **5 : 8** |

## 트리거에서 쓰는 시간이 서로 다르다

| 쓰는 것 | 게임에서 1 = 실제 | 왜 |
| --- | --- | --- |
| `Countdown Timer` | **0.672초** | 정확히 16프레임마다 1 줄어든다 |
| `Elapsed Time` | **0.672초** | 같다. 노말 기준에 맞춰져 있다 |
| `Wait(N)` | N 밀리초 = 실제 N/1000초 | 실제 시간 기준 |
| 유닛 생산시간 (SCMD2) | 1 = 0.042초. **24 ≒ 1초** | 프레임 단위다 |
| 업그레이드·기술 시간 (SCMD2) | **노말 기준 초**. Fastest 실제로는 ×0.63 | 스팀팩 SCMD2 80 → 실제 약 50초 |

> **카운트다운 12 는 실제 8초다.** 제한 시간을 실제 초로 생각하고
> 12 를 넣으면 실제로는 8.06초다 — 30% 짧다. 동선 계산이 다 틀어진다.

```
실제 초 → 카운트다운 값:   n = round(실제초 / 0.672)
카운트다운 값 → 실제 초:   t = 값 * 0.672
```

| 실제로 주고 싶은 시간 | `Set Countdown Timer` 값 |
| --- | --- |
| 5초 | 7 |
| 10초 | 15 |
| 12초 | 18 |
| 30초 | 45 |
| 1분 | 89 |
| 3분 | 268 |

`Elapsed Time` 도 같은 자다. "3분 버티기" 는 `Elapsed Time(At least, 268)`.

## 하이퍼(터보) 트리거와의 관계

기본 트리거 주기는 **약 1.26초(30프레임)** 다. 하이퍼 트리거는
`Wait(0)` 63개 × 3벌로 이 주기를 프레임 단위까지 당긴다.

- 하이퍼가 없으면 모든 판정이 최대 1.26초 늦는다.
- 하이퍼를 깔면 조건이 참인 동안 **매 프레임** 돈다 — 잠금이 없는
  트리거는 1초에 스물네 번 돈다.

## 왜 이게 중요한가

내가 틀렸던 것들:

- OX 퀴즈 제한 시간을 "12초" 로 잡고 `Set Countdown Timer(Set To, 12)`
  를 넣었다. 실제로는 **8초**였다. 발판까지 걷는 거리를 12초 기준으로
  재 놓고 8초를 준 셈이다.
- `spatial.py` 의 "초당 세 칸" 계산도 카운트다운 값을 실제 초로 보고
  했다. 실제로는 더 빠듯하다.
