# CHK 섹션 레퍼런스

| 섹션 | 역할 및 참조 |
| --- | --- |
| `VER ` / `IVE2` | 맵 버전 및 형식 |
| `DIM ` / `ERA ` | 크기와 타일셋 |
| `MTXM` | 화면에 렌더하는 지형 데이터 |
| `TILE` | 기초 지형 데이터 |
| `UNIT` / `THG2` | 유닛·건물·자원 및 장식 배치 |
| `MRGN` | 로케이션과 Start Location 좌표 |
| `TRIG` | 실행 트리거 조건·액션과 소유자 |
| `MBRF` | 순차 미션 브리핑 동작 |
| `STR ` / `STRx` | 문자열 테이블 |
| `SPRP` | 맵 설명/제목 문자열 인덱스 |
| `UNIS` / `UNIx` | 사용자 지정 유닛 능력치 |
| `UPGR` / `PUPx` | 업그레이드 설정 |
| `PTEC` / `PTEx` | 기술 설정 |
| `FORC` / `OWNR` / `SIDE` | Force, 슬롯 소유/종류, 종족 설정 |
| `VCOD` | 보존이 필요한 검증/보호 데이터일 수 있음 |

섹션 길이와 참조 인덱스는 파일의 실제 CHK 헤더 및 MappingCore 타입과 대조한다. 섹션이 빠졌을 때 에디터/게임의 기본 동작은 맵 버전에 따라 검증한다. 기존 맵을 저장할 때 관계 없는 바이트를 정규화하거나 제거하지 않는다. 특히 `STR` tail 보존과 문자열 참조 삭제 동작은 저장 경로 구현을 따른다.
