# CHK 섹션 — 무엇이 어디에 있나

맵 파일(`.scm`/`.scx`)은 MPQ 아카이브이고, 그 안의 `staredit\scenario.chk`
가 맵 자체다. `splash-cli chk <맵> <출력.chk>` 로 꺼낸다.

CHK 는 `[4바이트 이름][4바이트 길이][내용]` 이 줄줄이 이어진 꼴이다.
**같은 이름이 여러 번 나올 수 있고, 뒤에 나온 것이 이긴다.** 그래서
읽을 때는 마지막 것을 쓴다.

```python
def sections(chk: bytes):
    out = collections.defaultdict(list)
    i = 0
    while i + 8 <= len(chk):
        name = chk[i:i+4]
        (n,) = struct.unpack("<i", chk[i+4:i+8])
        i += 8
        if n < 0:            # 음수 = jump section (뒤로 이동). 여기선 건너뛴다
            continue
        out[name].append(chk[i:i+n])
        i += n
    return out
```

## 자주 건드리는 섹션

| 이름 | 무엇 | 자주 틀리는 것 |
| --- | --- | --- |
| `DIM ` | 맵 크기 | |
| `ERA ` | 타일셋 번호 | 하위 3비트만 쓴다 (`& 7`) |
| `MTXM` | 지형 타일 | 두뎃이 여기 **눌러 담긴다** |
| `TILE` | 밑 지형 | MTXM 과 따로 논다 |
| `ISOM` | ISOM 마름모 값 | 직접 찍으면 `Modified` 가 서고 다시 못 푼다 |
| `DD2 ` | 두뎃 항목 | 실제 맵은 **거의 비어 있다** (지형으로 눌러 담겨서) |
| `THG2` | 스프라이트 | |
| `UNIT` | 놓인 유닛 | |
| `MRGN` | 로케이션 | 늘 255칸 |
| `TRIG` | 트리거 | 2400바이트 고정 크기 구조가 줄줄이 |
| `MBRF` | 미션 브리핑 | TRIG 와 같은 꼴. **개수 = 길이 / 2400** |
| `SPRP` | 맵 이름·설명 문자열 번호 | uint16 둘 |
| `STR `/`STRx` | 문자열 | `STRx` 는 오프셋이 4바이트. 한글 맵에 많다 |
| `UNIS`/`UNIx` | 유닛 능력치 | 앞 228바이트가 "기본값을 쓴다" 표시 (**0 이면 고친 것**) |
| `UPGS`/`UPGx` | 업그레이드 설정 | 앞 61(46)바이트가 같은 표시 |
| `FORC` | 세력 | 시작 위치 섞기 깃발이 여기 |
| `OWNR`/`SIDE` | 슬롯 주인·종족 | |
| `MASK` | 시야 가리개 | |

`x` 가 붙은 것(`UNIx`·`UPGx`·`STRx`)은 브루드워 확장판이다. 둘 다 있으면
확장판이 이긴다.

## 실측 — 사람들은 무엇을 채우나

내려받기 상위 유즈맵 127장을 CHK 로 직접 뜯어 세었다 (2026-09 기준).

| 항목 | 중앙값 | 사분위 | 0 아닌 맵 |
| --- | --- | --- | --- |
| **능력치를 고친 유닛 종** (`UNIS`/`UNIx`) | **108종** | 78~141 | **98%** |
| 고친 업그레이드 (`UPGS`/`UPGx`) | 9개 | 4~27 | 85% |
| 브리핑 트리거 (`MBRF`) | **2개** | 1~4 | **85%** |
| 맵 설명 (`SPRP`→`STR`) | **72바이트** | 36~105 | **95%** |

읽는 법:

- **유닛 능력치는 거의 모든 맵이 고친다.** 108종은 "쓰는 유닛만" 이
  아니라 통째로 만지는 것에 가깝다. 아무것도 안 고친 맵은 127장 중 2장.
- **브리핑은 두 트리거가 표준이다.** 한 트리거에 다 몰아넣는 것이 아니라
  나눠서 흐르게 한다.
- **맵 설명은 짧다.** 중앙 72바이트면 한글로 서른 자 남짓이다. 가격·수치를
  다 적을 자리가 아니다 — 그건 브리핑이 할 일이다.

> 이 셋을 내가 거꾸로 했다. 유닛 능력치는 하나도 안 고치고, 브리핑은
> 한 트리거에 몰아넣고, 설명에는 상점 가격까지 적었다.

## 주의

`MBRF` 개수를 앞 4바이트에서 읽으면 안 된다. `TRIG` 와 같이 **개수 칸이
없고** 고정 크기 구조가 이어진 꼴이다. 처음에 그렇게 읽어 "브리핑 쓰는
맵 0%" 라는 틀린 수가 나왔다.
