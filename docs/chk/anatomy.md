`data/anatomy.json`. 지형·유닛·트리거는 따로 쟀고

## 읽을 것 셋

### 1. 유즈맵은 **업그레이드와 기술을 고친다**

| | 유즈맵 |
| --- | --- |
| 업그레이드를 하나라도 고친 맵 | 대부분 (중앙 **7가지**) |
| **90% 지점** | **61가지 — 전부** |
| 기술 90% 지점 | **44가지 — 전부** |

밀리맵은 중앙 0 이다. **유즈맵만의 버릇**이고, 내 생성기는 하나도
안 고치고 있었다.

`splash-cli upgrade set` · `tech set` 으로 한다. 시작 단계를 미리
올려 두거나(`Initial Level`), 최대 단계를 막거나, 비용을 바꾼다
([../unit/settings.md](../unit/settings.md)).

### 2. 슬롯 짜임이 정해져 있다

| | 유즈맵 중앙 |
| --- | ---: |
| 사람(열림) | **6** |
| 컴퓨터 | **2** |

"사람 6 + 컴퓨터 2" 가 표준형이다. 컴퓨터 둘은 대개 **적과 보스**다 —
트리거가 쓰는 적 플레이어는 컴퓨터여야 아무도 안 앉아도 유닛이 나온다.

밀리맵은 사람 4 · 컴퓨터 0 이다.

### 3. 종족 '선택 가능' 이 갈린다

| | 그런 슬롯이 있는 맵 |
| --- | ---: |
| **밀리맵** | **90%** |
| **유즈맵** | **2%** |

밀리맵은 종족을 고르게 두는 것이 정상이고, 유즈맵은 거의 안 쓴다.
**다만 2% 는 0% 가 아니다** — 컴까기처럼 본진을 짓는 유즈맵은 쓰는
것이 맞다. 그래서 검사기도 **그 슬롯에 유닛을 깔아 두었을 때만**
잡는다 ([../usemap/essentials.md](../usemap/essentials.md)).

## 세력 깃발은 켜 둔다 — 안 먹어도

| 깃발 값 | 유즈맵 | 밀리맵 |
| ---: | ---: | ---: |
| **14** (동맹 + 동맹승리 + 시야공유) | 1126 | 325 |
| **15** (위 + 무작위 스타팅) | 531 | 497 |
| 0 (아무것도 안 켬) | 140 | 144 |

**사람들이 실제로 켠다.** 그런데 카페 [기초4] 는 **동맹 · 시야공유 ·
동맹승리 깃발이 "체크하든 말든 적용 안 된다"** 고 적는다.

> **⚠ 둘 중 어느 쪽이 맞는지 가르지 못했다.** 게임을 돌려 확인하지
> 못했고, 밖에서 교차 확인할 자료도 못 찾았다. 에디터가 기본으로
> 켜 두어서 값이 저렇게 몰린 것일 수도 있다.
>
> **그래서 이렇게 한다** — 깃발은 켜 두되 **믿지 않고 트리거의
> `Set Alliance Status` 로 한 번 더 묶는다.** 어느 쪽이 맞든 맵은
> 뜻대로 돈다.

무작위 스타팅(`RandomizeStartLocation`)은 **효과가 있다** — 켜져 있으면
색과 시작 위치가 섞여, 자리마다 트리거가 다른 맵이 망가진다.

## 한계에 얼마나 붙어 있나

출처: 스타 에디터 아카데미 `에디터의 모/든/것`
[에디터의 제한들](https://cafe.naver.com/edac/book1678930/19971) + 실측.

| 한계 | 값 | 실측이 닿는 곳 |
| --- | ---: | --- |
| **맵의 유닛 총수** | **1650** (건물·자원 포함) | 유즈맵 최대 2476 유닛 — **넘는 맵이 있다** |
| **스트링 종류** | **1024** | **중앙이 이미 1024** |
| 유닛 속성 (CUWP) | 64 | 유즈맵 90% 가 42, 최대 64 |
| 스위치 | 256 | 최대 256 |
| **트리거 하나의 조건** | **16개** | — |
| **트리거 하나의 액션** | **64개** | — |
| 트리거 수 | — | 최대 26,960 (밀리 옵저버 맵) |

유닛 한계에 걸리면 게임에서 **`Cannot`** 이 뜬다. 스트링 한계에
걸리면 **로케이션 이름도 못 고치고 글도 못 띄운다.**

> 실측 유즈맵의 유닛 최대가 2476 인데 한계가 1650 이다. 세는 자가
> 다르거나(맵에 배치한 것 vs 게임 안에 동시에 존재하는 것), 그 맵이
> 트리거로 지워 가며 굴리는 것이다. **가르지 못했다.**

([../trigger/briefing-strings.md](../trigger/briefing-strings.md)).

## 잴 때 틀렸던 것

`OWNR` 값을 5·6 둘 다 사람으로 잡았다가 숫자가 이상했다. **5 가
컴퓨터, 6 이 열림(사람)** 이다. `SIDE` 의 '선택 가능' 도 6 이 아니라
**5** 다. 정본은 `src/cli/cli_common.cpp` 의 `kSlotTypes` · `kRaces` 다.

```
OWNR  0 사용 안 함 · 1 컴퓨터(게임) · 2 사람(게임) · 3 구조 대상
      5 컴퓨터 · 6 열림 · 7 중립 · 8 닫힘
SIDE  0 저그 · 1 테란 · 2 프로토스 · 3 독립 · 4 중립
      5 선택 가능 · 6 무작위 · 7 사용 안 함
```
