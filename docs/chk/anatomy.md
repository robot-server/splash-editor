# CHK 데이터와 제작 기능의 연결

CHK는 지형·오브젝트·로케이션·트리거·문자열·유닛 설정 등을 각 섹션에 저장한다. 기능을 조사할 때는 섹션 하나만 떼어 읽지 않고 참조 관계를 따라간다.

| 기능 | 관련 섹션 | 검토할 연결 |
| --- | --- | --- |
| 슬롯/시작 | `OWNR`, `SIDE`, `FORC`, `MRGN` | 소유자, 종족, 세력과 Start Location |
| 지형 표시 | `DIM `, `ERA `, `MTXM`, `TILE` | 크기/타일셋, 화면 지형과 기초 지형 |
| 유닛/자원 | `UNIT`, `THG2` | 좌표, 플레이어, 유닛 종류 및 실제 배치 가능 여부 |
| 상호작용 | `TRIG`, `MRGN`, `STR ` / `STRx` | 조건·액션이 참조하는 위치와 텍스트 |
| 미션 브리핑 | `MBRF`, `STR ` / `STRx` | briefing 액션과 문자열 |
| 유닛 설정 | `UNIS`, `UNIx` | 기본값 플래그와 각 유닛 설정 |

섹션 형식은 [sections.md](sections.md)를 본다. 저장 결과 비교는 MPQ 압축 바이트가 아니라 CHK 섹션과 보존 영역을 기준으로 한다. 기존 맵 수정에서는 범위 밖 데이터를 보존한다.
