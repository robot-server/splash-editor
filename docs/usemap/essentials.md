# 유즈맵이 "열리기는 하는가"

**재미보다 앞선다.** 아래를 빠뜨리면 게임이 시작되지 않거나, 만든 것이
통째로 무시된다.

출처: 스타 에디터 아카데미
[[기초4] 유즈맵의 필수 요소](https://cafe.naver.com/edac/book5095361/76351)
+ 실제로 겪은 것.

## 1. 종족을 못 박는다 — `User Select` 는 재앙이다

카페가 그대로 적어 두었다.

> **User Select** : 유저 선택. … 이걸 선택하면 해당 플레이어는 밀리맵
> 마냥 **배치된 유닛/건물들이 다 무시되고** 스타트로케이션에
> **본진건물 + 일꾼 4마리**로 시작합니다.

대부분의 유즈맵에서는 치명적이다. 만들어 놓은 병력이 하나도 안 나오고,
건물 짓는 사이에 게임이 끝난다. 실측 유즈맵 329장의 사람 슬롯 종족은
**테란 72% · 저그 14% · 프로토스 11% · 선택 가능 1%** 다.

### 다만 **밀리맵 컨셉을 늘린 유즈맵은 일부러 쓴다**

컴까기(컴퓨터와 싸우기)처럼 **사람이 본진을 짓고 종족을 골라 하는** 맵은
`User Select` 가 맞다. 그런 맵에서는 "본진 + 일꾼 4마리로 시작" 이 버그가
아니라 **원하는 것**이다.

| 이 맵이 | 종족 |
| --- | --- |
| 사람이 유닛을 **받아서** 논다 (디펜스·키우기·퀴즈·술래잡기·컨트롤) | **못 박는다** (테란이 표준) |
| 사람이 **본진을 짓고** 논다 (컴까기·팀플 변형·밀리 확장) | **User Select** |

가르는 기준은 장르 이름이 아니라 **"배치한 유닛이 필요한가"** 다.
맵에 사람 소유 유닛을 깔아 두었는데 `User Select` 면 그 유닛이 전부
사라진다 — 그때만 잘못이다.

실측: scmscx 내려받기 상위 유즈맵 179장에는 `User Select` 슬롯이 **0장**
이다. 인기 상위는 죄다 "유닛을 받아서 노는" 쪽이라 그렇다. 컴까기 계열은
따로 찾아 봐야 표본이 잡힌다.

| Owner | 뜻 |
| --- | --- |
| `Human` | 사람 |
| `Computer` | 컴퓨터 |
| `Rescuable` | 가까이 가면 그 플레이어 소유로 바뀐다 |
| `Neutral` | 중립 (자원의 플레이어12 와는 다르다) |
| `Unused` | 안 씀 |

플레이어 9~11 은 정상 플레이어가 아니라 만질 필요가 없다. 12 는 중립.

`.scm` 이면 **색 변경이 적용되지 않는다.**

## 2. 세력 깃발을 믿지 않는다 — 트리거로 묶는다

출처는 **한 편뿐**이다 — 스타 에디터 아카데미
[[기초4] 유즈맵의 필수 요소](https://cafe.naver.com/edac/book5095361/76351).

> 그 외 **Allied, Shared Vision, Enable Allied Victory 는 체크하든 말든
> 적용 안되니** 무시해도 됩니다. … 같은 세력에 넣었다고 자동으로 서로
> 동맹이 되고 다른 세력이라고 자동으로 적이 되고 이런건 없습니다.
>
> 컴퓨터는 기본적으로 컴퓨터끼리 동맹 상태이며, 플레이어와 컴퓨터는
> 적대상태, 플레이어 끼리도 적대상태가 기본입니다.

> **⚠ 나는 이것을 확인하지 못했다.** 게임을 돌려 보지 못했고, 밖에서
> 교차 확인할 자료도 못 찾았다. MappingCore 는 깃발 이름
> (`RandomizeStartLocation` · `RandomAllies` · `AlliedVictory` ·
> `SharedVision`)만 적어 두고 효과를 말하지 않는다.
>
> 그런데 실측에서는 **사람들이 그 깃발을 켠다** — 유즈맵의 깃발 값이
> 14(동맹+동맹승리+시야공유)와 15가 압도적이다
> ([../chk/anatomy.md](../chk/anatomy.md)). 켜는 것이 관행인지, 실제로
> 먹어서인지는 **가르지 못했다.**
>
> **그래서 이렇게 한다** — 깃발은 켜 두되, **믿지 않고 트리거로 한 번
> 더 묶는다.** 깃발이 먹으면 중복일 뿐이고, 안 먹으면 트리거가 살린다.
> 어느 쪽이든 맵은 뜻대로 돈다.

카페가 말하는 기본 상태:

```
컴퓨터 ↔ 컴퓨터   동맹
사람   ↔ 컴퓨터   적
사람   ↔ 사람     적        ← 여기가 함정
```

**협동 유즈맵이면 트리거로 직접 묶는다.**

```python
T += scmap.part_ally_humans(["Player 1", "Player 2", "Player 3"])
```

> 내가 틀렸던 것: `--allied-victory on --shared-vision on` 을 켜 놓고
> "사람끼리는 한 편" 이라고 적어 두었다. 아무 일도 일어나지 않았다.

**`Randomize Start Location` 은 반대로 효과가 있다.** 하나라도 켜져
있으면 색과 시작 위치가 그 세력 안에서 섞인다. 자리마다 트리거가 다른
맵(디펜스 경기장 등)은 그대로 망가진다 — **끈다.**

## 3. 그 밖에 빠뜨리기 쉬운 것

| 빠뜨리면 | 무슨 일이 나는가 |
| --- | --- |
| 스타팅 포인트 없음 | **게임이 시작되지 않는다.** 최소 2개 |
| 사람 슬롯 수 ≠ 스타팅 수 | 대기실에서 스타팅 없는 자리를 받는 사람이 생긴다 |
| 트리거가 쓰는 적이 "열림" | 아무도 안 앉으면 그 유닛이 안 생긴다. **컴퓨터**여야 한다 |
| 하이퍼 트리거 없음 | 모든 판정이 최대 1.26초 늦는다 |
| 시야를 안 열어 줌 | 사람 화면이 깜깜하다. 실측 74%가 Map Revealer 를 쓴다 |
| `.scx` 인데 버전이 Hybrid | 럴커·메딕·커세어를 못 쓴다 |
| 자원 유효 비트 꺼짐 | 남은 양을 적어도 게임이 **0 으로 본다** |

스타팅은 한 플레이어당 **1개까지**다. `Units - Neutral - Start Location`
에 있고, **Unit Sprites 나 Pure Sprites 쪽에서 찾으면 안 된다**
(스프라이트로 놓으면 튕기는 것이 많다 — [crashes.md](../game/crashes.md)).

## 4. 유닛 능력치를 고친다

실측 유즈맵 127장 중 **98%가 고친다. 중앙 108종.**
아무것도 안 고친 맵은 두 장뿐이다 ([chk/sections.md](../chk/sections.md)).

유즈맵은 "기본 스타크래프트" 가 아니라 **그 맵만의 규칙**이다. 체력·
공격력·값을 맵에 맞게 바꾸는 것이 표준이다.

## 5. 밀리맵과 다른 점

| | 밀리 | 유즈 |
| --- | --- | --- |
| 배치한 유닛 | **중립 자원·동물 말고 전부 무시** | 그대로 나온다 |
| 자원 주인 | 반드시 중립(플레이어12) | 아무나 |
| 종족 | 사람이 고른다 | 맵이 못 박는다 |
| 트리거 | 거의 안 쓴다 | 알맹이다 |

밀리맵에서 플레이어1 의 마린을 아무리 깔아도 나오지 않는다 — 나왔다면
플레이어1 만 마린을 갖고 시작하는 사기 맵이 된다.

## 값으로 만드는 연출 세 가지

출처: 스타 에디터 아카데미 `에디터의 모/든/것`
[유닛 체력표시만 안보이게 하기](https://cafe.naver.com/edac/book1678930/) ·
[Start Location 응용효과](https://cafe.naver.com/edac/book1678930/) ·
[자원/건물 겹치기(Stack) 이용](https://cafe.naver.com/edac/book1678930/).

### 체력 막대를 감춘다

**실드를 10000 이상으로 올리면 체력 표시가 사라진다.** 무적이 되는
것도, 체력이 무한이 되는 것도 아니다 — 피해는 그대로 받는다.

```sh
splash-cli unitdef set 맵 "유닛" --default off --hp 40 --shields 10000 --in-place
```

RPG 나 스킬 맵에서 **체력을 숫자로 따로 보여 주고** 막대는 감출 때 쓴다.

> **프로토스는 예외다.** 원래 실드가 있으므로, 프로토스 유닛·건물은
> **실드를 0% 로 고정**해야 같은 효과가 난다
> (`Modify Unit Shield Points ... to 0%`).

### `F2`·`F3`·`F4` 로 특정 건물에 가게 한다

게임은 **처음 시작한 자리를 기억**하고, `F2`~`F4` 중 아무거나 누르면
그 자리로 화면이 간다. **스타팅 포인트를 중심 건물 위에 놓으면**
플레이어가 단축키 한 번으로 그 건물로 돌아온다.

상점 · 스킬 건물처럼 자주 돌아가야 하는 곳에 놓는다. 트리거를 하나도
안 쓰고 되는 편의다.

### 겹치기(Stack)

SCMDraft2 에서 유닛·건물을 고르고 우클릭 → **`Stack Selected`** →
겹칠 수를 넣는다. 빠른 무한 맵의 자원 더미, 유즈맵의 겹친 건물이 이것
이다.

> **겹치기를 한 맵을 기본 에디터(X-tra · 세디터 · 캠페인 에디터)로
> 열면 겹친 것이 오류와 함께 모두 사라진다.** 겹치기는 **맨 나중에**
> 하고, 이후 수정도 고급 에디터로만 한다.

우리 CLI 는 같은 자리에 그냥 놓으면 된다 —
`splash-cli unit place 맵 <유닛> <x> <y>` 를 여러 번.
