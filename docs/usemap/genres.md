# 유즈맵 장르별 공간 설계

## [지형/배치 메커니즘]

- 메커니즘 이름: 장르 규칙을 읽히게 하는 플레이 공간 구획
- 적용 이유/목적: 지형 형태는 플레이어가 어디에서 선택하고, 이동하고, 위험을 감수하는지를 전달해야 한다.
- 구체적 규칙 (타일 단위, 좌표 단위, 배치 각도, 언덕 연결 규칙 등): 퀴즈/선택형 공간은 선택 영역과 탈락·결과 영역을 시각적으로 구분하고 트리거 로케이션을 각 영역에 정렬한다. 탐험·전투형 공간은 분기 경로와 합류 지점, 스폰 위치와 목표 위치를 기능별로 정한다. 장르 이름만으로 사각형 또는 ISOM을 고정하지 않는다. 필요한 플레이 경로와 시야를 먼저 정한 뒤 타일 모드를 택한다.
- 잘된 예시 및 실패하는 나쁜 예시: 선택 패드와 해당 결과가 직접 대응하고 경계가 명확한 공간은 성공이다. 로케이션이 시각적 표식과 어긋나거나 스폰 적이 막힌 장식 지형 안에 놓이는 구성은 실패다.

# [에디터 타일/배치 제약사항]

- 지형 간 연결 규칙: 지상 이동을 플레이 규칙에 사용하는 경우 분기·합류·탈출 경로가 걷기 영역으로 이어져야 한다. 순간이동/생성 로케이션은 이동 연결과 혼동되지 않게 구별한다.
- 유닛 길막/동선 보장 규칙: 상호작용 로케이션에는 조건 검사 대상이 들어갈 수 있는 공간을 두고, 생성 로케이션에는 생성 후 목표로 이동할 수 있는 경로를 둔다. 실제 게임에서 트리거 조건과 유닛 이동을 확인한다.

장르 분류 집계는 공간 구획의 설계 근거가 아니다. 각 맵의 규칙과 트리거를 기준으로 구성한다.
