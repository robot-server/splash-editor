# [트리거/로직 패턴]

## 효과음과 텍스트 피드백 동기화

- 패턴 이름: 상태 변화에 맞춘 WAV 피드백
- 구현하고자 하는 기능: 구매·선택·웨이브·목표 진입의 결과를 시각 안내와 소리로 전달한다.
- 조건(Condition) 및 액션(Action) 구조 체인: 기능 조건 → 실제 상태 변화 → `Display Text Message`와 `Play WAV`를 같은 결과 흐름에 배치한다. 미션 브리핑 내 음성은 순차 briefing 액션으로, 게임 중 효과음은 일반 trigger action으로 구분한다.
- 예외 처리/버그 방지 로직 (예: 스위치 리셋, 트리거 순서 등): 반복 trigger에서 사운드가 매 판정마다 중복 재생되지 않도록 토큰 소비, 상태 변화 또는 재진입 간격을 둔다. briefing의 대기시간과 WAV 길이를 따로 정하고 실제 게임에서 잘림/중첩을 확인한다. [강좌: 트리거 액션](https://cafe.naver.com/edac/book5095361/76412), [미션 브리핑](https://cafe.naver.com/edac/book5095361/76453).

특정 장르에서 자주 쓰인다는 통계는 효과음 필요성이나 재생 빈도의 근거로 사용하지 않는다.
