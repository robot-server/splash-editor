# DatEdit · FireGraft — **맵이 못 고치는 것을 고치는 곳**

출처: 스타 에디터 아카데미
[DatEdit 1부](https://cafe.naver.com/edac/book5095361/76627) ·

[FireGraft](https://cafe.naver.com/edac/book5095361/76689).

맵의 유닛 설정(`unitdef set`)이 고칠 수 있는 것은 다섯 가지뿐이다
([../unit/settings.md](../unit/settings.md)). **사거리 · 공격 형태 ·
이동 속도 · 버튼**을 바꾸려면 게임 데이터 자체를 건드려야 한다.

> **맵이 아니라 게임을 바꾸는 일**이다. 그 맵을 하는 사람의 게임에만
> 적용되지만, EUD 를 통해 들어가므로 [../eud/limits.md](../eud/limits.md)
> 의 안전 규칙이 그대로 걸린다.

## DatEdit 은 **게임 시작 후 트리거로** 적용된다

SCMDraft2 의 유닛 설정과 결정적으로 다른 점이다.

| | 맵에 미리 배치한 유닛에 |
| --- | --- |
| 적용된다 | **무기 · 쉴드 사용 여부 · 방어구** |
| **적용 안 된다** | **나머지 대부분**, 특히 그래픽·외형 관련 (이동 속도 포함) |

> **SCMD2 에서 정할 수 있는 값은 DatEdit 에서 건드리지 않는다.**
> 체력 · 방어력 · 공격력 · 생산 비용처럼 양쪽에서 되는 것을 DatEdit
> 쪽에서 만지면, **미리 배치한 유닛에 안 먹는** 부작용만 생긴다.

## 무기 탭 — 공격력은 유닛이 아니라 무기에 있다

> 더미 유닛인 멩스크와 듀갈의 공격력이 노라드와 공유되는 까닭도
> **세 유닛이 한 무기를 쓰기 때문**이다.

내가 잰 것과 같다 ([../unit/heroes.md](../unit/heroes.md)).

| 칸 | |
| --- | --- |
| **투사체 수** | **1회 공격에 나가는 발 수.** 2 면 두 발. **3 이상은 1 로 적용**. 근접 무기는 안 걸린다 |
| 공격속도 | 프레임 (24 ≒ 1초). **아무리 낮춰도 공격 모션 길이 아래로는 안 내려간다** |
| 데미지 형식 | 폭발 · 진동 · 노멀 · **방어력 무시(스톰)** · 알수없음(독립형) · 없음(자원 채집) |

마법도 무기로 친다. 다만 **유닛 무기를 마법으로 바꾸면 마법 효과만
나오고 피해는 안 들어간다.**

## 비행정보 탭 — **이동 속도를 못 바꾸는 까닭**

| 칸 | |
| --- | --- |
| 최고속도 · 가속 · 제동거리 | 말 그대로 |
| 회전반경 | 0~128. **0 이면 한 방향으로 직진하다 맵 경계에서 튕긴다.** 1 이면 그래픽만 돈다 |
| **이동제어** | **여기가 핵심** |

> 위 값들은 **이동제어가 `Flingy.dat 제어` 일 때만 먹는다.**
> 마린 · 저글링 같은 유닛은 `Iscript.bin 제어` 라서 **바꿔도 소용없다.**
> `Flingy.dat 제어` 로 돌리면 속도를 고칠 수 있지만 **움직임이 공중
> 유닛처럼 부자연스러워진다.** 그래도 안 먹으면 가속도를 늘린다.

이것이 `splash-cli unit-stats` 에서 마린 · 질럿 · 드라군의 `speed` 가
**1 로 나오는 까닭**이다 — 자리표시자다. `move_control` 을 함께 본다
([../unit/heroes.md](../unit/heroes.md)).

## 건설크기와 높이 (2부)

| 값 | |
| --- | --- |
| **건설크기 가로·세로 중 하나를 0** | 모습이 안 보이고 클릭도 미니맵 표시도 안 된다. **나머지 기능은 정상** |
| **하나를 1** | 건물이 **지형·유닛을 무시하고 아무 데나** 지어진다 |
| 저그 건물 | **최소 32×32 여야 생성될 때 크립이 생긴다** |
| 높이 0·1 | 비콘처럼 위로 유닛이 지나가는 값. **아무 유닛에나 줘도 통과가 되지는 않는다** |
| 높이 2~11 | 보통 지상 |
| 높이 12~19 | **공중. 못 가는 지형을 지난다.** 같은 공중이라도 높을수록 위에 그려진다 |
| 얼굴사진 | **Idle Portrait 가 아니면 튕긴다** |
| 시야 | **0 이면 지상 유닛은 아주 조금 남는다. 12 이상이면 튕긴다** |
| 탑승 필요량 | **1·2·4 말고 다른 값이면 타기는 해도 못 내린다** |
| 탑승 제공량 | **9 이상이면 튕길 수 있다** |
| 저그 체크 | 체크되어 있으면 **유닛 생산이 안 된다** (인페스티드 커맨드 센터만 예외) |
| 테란만 체크 | **계급이 보인다** |

**"유닛기제 & 팔레트" 에 체크되어야 `Create Unit` 트리거로 만들 수
있다.** 초상화 더미 넷이 트리거로 안 만들어지는 까닭이 여기다
([../unit/heroes.md](../unit/heroes.md)).

## FireGraft — 버튼셋과 요구사항

| | |
| --- | --- |
| 무엇 | 버튼셋 같은 GUI 와 **요구사항** |
| 어디서 | **EUD Editor 2** 를 쓴다 (1 은 고려할 것이 많아 까다롭다) |

> **켜기만 해도 버그가 생긴다.** 같은 버튼셋을 쓰는 유닛끼리 다중
> 선택해도 버튼셋이 제대로 안 나온다 — **마린 + 파이어뱃을 함께 골라도
> 스팀팩이 안 뜬다.** 베슬과 베슬 영웅도 마법 버튼이 안 뜬다.

버튼에 명령을 붙일 때는 **요구사항을 반드시 건다.** 안 걸면 건물
공격 명령이 캐논 · 성큰 · 터렛 · 트랩류로 제한되어 있어서 **플레이어
명령을 무시하고 제멋대로 공격한다.** 요구사항 용량이 넘치면 안 쓰는
트랩류 요구사항을 빼서 자리를 만든다.

상태기능(콘솔 갱신 속도)은 유닛 이름 · 계급을 자주 바꾸는 맵이면
**기능 7(항상 빠름)** 로 둔다.

## 건물에 무기 달기 (예제)

[[예제] 건물에 무기 부여하기](https://cafe.naver.com/edac/book5095361/88883)
가 밟는 차례다.

1. **안 쓰는 무기 번호를 고른다** — 117번 이상의 `Gauss Rifle (Unused)`.
   기존 무기(야마토포 등)를 그대로 쓰면 **원래 유닛까지 바뀐다.**
2. 유닛의 지상·공중 무기를 그 번호로. **부가사거리도 사거리에 맞춘다.**
3. **공격가능각을 128 로.** 건물은 방향을 못 돌려 12시로 고정이라,
   좁게 두면 12시 쪽만 공격한다.
4. 고급정보에서 **전투에 반응** 체크, AI 를 캐논·성큰과 같게.
5. 버튼셋을 캐논에서 복사, **요구사항에 그 유닛을 추가**.
6. **이미지 스크립트에 공격 모션을 넣는다.** 없으면 공격 순간 유닛이
   투명해지고 고인돌이 생기며 공격이 안 나간다.
