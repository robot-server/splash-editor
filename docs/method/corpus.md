# 원본 자료 근거 작성 원칙

제작 지식은 실제 맵 원본 또는 스타 에디터 아카데미 강좌 원문에서 확인한다. 밀리맵을 인용할 때는 렌더, 시작·자원 배치, 고저 연결을 한 지도 안에서 함께 보고, 유즈맵은 기능이 완성되는 조건·액션·상태 전이를 같은 트리거와 주변 로케이션에서 연결해 읽는다. 강좌는 해당 기능을 설명하는 원문 페이지에, 맵 사례는 제목을 드러내지 않은 scmscx ID 링크에 연결한다.

맵의 사용 빈도는 기능의 목적이나 구현을 설명하지 않으므로 설계 기준으로 옮기지 않는다. 원본에서 직접 관찰한 체인과 추가로 권장하는 예외 처리·검증을 구분한다. 원문이나 게임 동작을 확인하지 못한 세부사항은 추측으로 채우지 않는다. 로컬 원본은 `_local-corpus/`에서 열고, CHK의 조건·액션과 맵 배치·렌더를 같은 ID로 대조한다.

## 기능을 맵 안에서 판별

TRIG 데이터의 존재나 트리거 개수만으로 밀리/유즈맵을 나누거나 기능을 추론하지 않는다. 밀리 원본에서도 시작 자원 설정, 오프닝 소리·타이틀 표시, 표준 승패 체인을 트리거로 처리한 사례가 있다. 각 맵에서 트리거 소유자, 조건, 액션 순서, 바뀌는 상태를 따라가고 그 효과가 어떤 슬롯·Force·위치에 적용되는지 같은 맵의 설정과 대조한다. 유즈맵 기능은 대응하는 로케이션·유닛·지형과 함께 읽는다.
