# 사실을 확인하고 기록하는 방법

## 근거의 종류

- 에디터/게임 강좌 원문: UI 조작법, 옵션 의미, 트리거 실행 순서와 작성자가 보여 준 동작의 근거다. 강좌가 다룬 버전과 문맥을 함께 본다.
- 설치 데이터와 프로그램 코드: 유닛, 타일, 파일 형식처럼 저장된 데이터 또는 이 저장소 도구가 실제 검사하는 범위를 확인한다. 도구의 검사 범위를 게임 규칙으로 확대 해석하지 않는다.
- scmscx 맵 원본: 한 제작자가 특정 기능을 어떤 조건·액션·상태·위치 조합으로 구현했는지 보여 준다. 이 구현이 보편 규칙임을 뜻하지 않는다.
- 게임 실행: 배치, 경로, 생성, UI 표시 등 런타임 행위를 확인하는 근거다. 실행하지 않은 경우 문서에 그 제한을 적는다.

## 기록 방식

규칙마다 출처 링크 또는 파일 경로를 두고, 관찰 사실과 설계 권고를 분리한다. 맵 원본은 제목 대신 scmscx ID 링크로 연결하고, 재현 가능한 기능 체인과 배치 맥락을 함께 적는다. 원문에서 확인되지 않는 실패 경로와 안전장치는 확정 사실로 적지 않는다. 평균·중앙값·빈도는 제작 파라미터로 사용하지 않는다.
