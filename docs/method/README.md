실측 색인과 측정 산출물은 재현·검증 자료다. 제작 시 기능을 설계할 때는
표본 비율이나 중앙값을 규칙으로 삼지 말고, 적용하려는 조건·액션·상태 변화가
드러나는 실제 맵과 강좌 근거를 확인한다. 적용용 패턴은
[유즈맵](../usemap/functional-design.md)과
[밀리맵](../melee/resource-sites.md)을 참고한다.

## 규칙

> **짐작해서 적지 않는다. 잰 것만 적는다.**
>
> 잰 값은 적어 둔다 — 매번 다시 재는 것이 더 비효율이다. 대신
> **어떻게 쟀는지를 반드시 함께 적는다.**
