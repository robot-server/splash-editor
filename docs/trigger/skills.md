# 스킬 — **웨잇으로 만들지 않는다**

출처: 스타 에디터 아카데미
[[예제] 간단한 스킬 만들기](https://cafe.naver.com/edac/book5095361/76591).

유즈맵의 "스킬" 은 대개 이렇게 생겼다 — 캐릭터 위에 유닛이 잠깐
생겼다가, 때리고, 사라진다. 그것을 여러 번 되풀이한다.

## 왜 웨잇으로 만들면 안 되나

```
스카웃 영웅 생성 → Wait(n) → 파괴 → 생성 → Wait(n) → ...
```

혼자 쓰는 맵이면 된다. 그런데 **웨잇 꼬임**이 난다.

정확히 말하면 `Wait` 상태는 **트리거를 실행하는 플레이어마다 하나**다.

| | |
| --- | --- |
| 플레이어가 **서로 다르면** | 각자 타이머라 **안 꼬인다** |
| **같은 플레이어**가 웨잇 흐름을 둘 이상 가지면 | **꼬인다** |

유즈맵에서 스킬을 `All Players` 나 한 시스템 플레이어에 몰아 두면
바로 여기에 걸린다. 사람마다 트리거를 나눠도, **그 사람이 스킬을 둘
동시에 쓰면** 또 걸린다 ([execution.md](execution.md)).

> **어지간한 것은 다 데스 트리거로 만든다.**

## 데스값을 타이머로 쓴다

```
항상          데스값 −1
스킬 사용시   데스값 = N
데스값 == N    → 스카웃 영웅 생성
데스값 == N−3  → 스카웃 파괴
데스값 == N−4  → 스카웃 생성
...
```

데스값이 **저절로 줄어드는 시계**가 된다. 조건은 전부 `Deaths` 라
웨잇이 없고, 사람이 몇이든 각자의 데스값으로 따로 돈다.

**터보 트리거를 걸면 데스값이 0.084초마다 1 준다.** 그러니

```
데스값 N−3 = 스킬 시작 0.084 × 3 = 0.252초 뒤
데스값 N−4 = 0.336초 뒤
```

연출 간격을 **0.084초 단위**로 설계한다.

## 짜는 틀

| 무엇 | 쓰는 것 |
| --- | --- |
| 유닛이 생길 자리 | **플레이어를 따라다니는 로케이션** (`Move Location`) |
| 적 위에 생길 자리 | **적을 따라다니는 로케이션** |
| 스킬마다 타이머 | **데스값 칸을 하나씩** (`var_skill1`, `var_skill2` …) |
| 스킬 고르기 | 건물에서 무엇을 뽑았나 (`Bring` 으로 센다) |
| 한 번에 하나만 | 다른 스킬 데스값이 0 일 때만 시작 |

데스값 칸은 **맵에 안 나오는 유닛**으로 고른다. 이름을 `var_skill1`
처럼 바꿔 두면 트리거가 읽힌다 → [death-counts.md](death-counts.md).

## 관용구 몇 가지

출처: 스타 에디터 아카데미 `Miscellaneous`

[수송 유닛 팁](https://cafe.naver.com/edac/book1867614/) ·
[Burrow 인식](https://cafe.naver.com/edac/book1867614/20254)).

### 넉백 — 밀어내기

공중 유닛을 쓰지 않아 **꼬일 걱정이 없다.**

1. 유닛을 잠깐 둘 **임시 자리 네 곳**(A·B·C·D)을 만든다. 서로 겹치지
   않고 지상 유닛이 들어갈 만큼 넓게.
2. 방향마다 로케이션을 만든다 — `Left` · `Right` 는 **가로가 짧고
   세로가 길게**, `Above` · `Below` 는 그 반대로.
3. 그 로케이션에 걸린 적을 해당 임시 자리로 옮겼다가, 원래 자리에서
   **한 칸 밀린 곳**으로 되돌린다.

| | |
| --- | --- |
| 좋은 점 | 트리거가 단순하고 공중 유닛을 안 써서 안 꼬인다 |
| 나쁜 점 | 지상이라 **지형을 탄다.** 세게 미는 것은 어렵다 |

### 스킬 쿨타임을 눈에 보이게

**테크 건물을 잠깐 뺏는다.**

1. 스킬 유닛이 **테크트리가 필요한 유닛**이어야 한다 (고스트 · 캐리어
   따위. 마린은 안 된다).
2. 스킬을 쓰면 그 테크 건물을 `Give Units` 로 **컴퓨터에게 넘긴다.**
3. 쿨타임이 끝나면 되돌려 준다.

버튼이 회색이 되므로 **플레이어가 쿨타임을 눈으로 본다.** 트리거로
글을 띄우지 않아도 된다.

### 버로우를 알아내기

저그 유닛이 버로우하면 그 위로 **지상 유닛이 지나간다.** 겹칠 수 있게
되는 것이다.

그 유닛에 `Move Location` 으로 로케이션을 붙여 두고, 그 자리에 **다른
지상 유닛이 함께 잡히는지** `Bring` 으로 본다. 잡히면 버로우 중이다.

### 수송에 태우면 이름이 길어진다

수송 유닛(벙커 · 드랍십 · 셔틀 …)에 태운 유닛은 **이름이 훨씬 길게
표시된다.** 스트링 탭에서 길이를 맞춰 두면 긴 이름을 쓸 수 있다.
