# [트리거/로직 패턴]

## 상태 변화·공간 효과·피드백을 하나의 액션 체인으로 구성

- 패턴 이름: 결과 액션과 플레이어 피드백 연결
- 구현하고자 하는 기능: 조건이 성립했을 때 게임 상태를 바꾸고 그 변화를 플레이어에게 전달한다.
- 조건(Condition) 및 액션(Action) 구조 체인: 조건에서 트리거 대상을 식별한 뒤 필요한 액션을 명시적인 순서로 둔다. 예를 들어 보상 체인은 자원 확인 → 선택 토큰 정리 → 유닛 생성 또는 소유권 변경 → 자원 갱신 → 메시지/효과음으로 구성할 수 있다. 실제 순서는 원본 기능 체인과 동시성 요구에 맞춘다.
- 예외 처리/버그 방지 로직 (예: 스위치 리셋, 트리거 순서 등): 액션 순서가 다음 조건 평가 또는 같은 플레이어의 다음 트리거 결과를 바꾸는지 확인한다. `Preserve Trigger`는 반복 실행이 의도된 경우에만 쓴다. `Display Text Message`의 Always Display 설정은 자막 설정에 따른 비표시를 막는 목적이다. 텍스트를 영구 UI로 고정하지 않는다. [강좌: 트리거 액션](https://cafe.naver.com/edac/book5095361/76412), [실행 원리](https://cafe.naver.com/edac/book5095361/76436).
