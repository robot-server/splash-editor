# 죽음 수(데스값) — 유즈맵의 변수

출처: 스타 에디터 아카데미 [중급1] 데스 트리거
(`cafe.naver.com/edac/book5095361/76491`) + 실측.

카페의 첫 줄이 이렇다.

> 데스값은 매우매우 중요한 개념입니다. 데스값도 모르고 배울려고도 하지
> 않는다면 유즈맵 만들지 마세요.

## 무엇인가

`Deaths(플레이어, 유닛, 견줌, 수)` 는 **그 플레이어의 그 유닛이 죽은
횟수**를 본다. 그런데 `Set Deaths` 액션으로 **임의로 바꿀 수 있다.**

그래서 죽음 수는 사실상 변수다. 그것도 아주 많은 변수 —
**모든 유닛 종류 × 모든 플레이어** 만큼 있다.

| | 값 |
| --- | --- |
| 시작값 | 0 |
| 최댓값 | 4,294,967,295 (2³² − 1) |
| 개수 | 유닛 종류(228) × 플레이어(8~12) |

## 변수로 쓸 유닛을 고르는 법

> Notice! 해당 맵에서 **쓰이지 않는 유닛**을 데스값 유닛으로 쓰는 게
> 좋습니다. 저글링을 데스값으로 써버리면 자기 저글링이 죽을 때마다
> 레벨이 올라버리겠죠?

카페는 `Flag` 를 쓴다. 그리고 —

> Flag 라고 하는 게 좀 눈에 잘 안 들어오면 **유닛 정보 설정에서 Flag 의
> 이름을 `var_level` 이런 식으로 변경해서** 쓸 수도 있습니다.

**유닛 이름을 바꿔서 변수 이름처럼 쓴다.** 이건 내가 안 하고 있던
것이다 — `Dark Swarm` 을 카운터로 쓰면서 이름을 그대로 뒀다.

## 어느 유닛이 안전한가 — 맵마다 다르다

"이 맵에 안 나오는 유닛" 이 안전하다. **게임이 저절로 만드는 것**까지
봐야 한다.

| 칸 | 이것이 맵에 있으면 못 쓴다 |
| --- | --- |
| `Dark Swarm` | 디파일러 |
| `Disruption Web` | 커세어 |
| `Scanner Sweep` | 컴샛·커맨드 센터 |
| `Protoss Scarab` | 리버 |
| `Protoss Interceptor` | **캐리어** |
| `Spider Mine` | 벌처 |
| `Nuclear Missile` | 고스트·핵 사일로 |
| `Zerg Cocoon` | 뮤탈리스크 |
| `Zerg Lurker Egg` | 히드라리스크 |
| `Zerg Egg` | 라바·해처리 계열 |
| `Flag` | (거의 안 쓰인다 — 카페의 기본 선택) |

내가 틀렸던 것: 기본 카운터를 `Protoss Interceptor` 로 두었다. 캐리어가
있는 맵에서는 인터셉터가 끊임없이 생기고 죽어 값이 엉망이 된다.

`scmap.MapResources.counter()` 가 맵이 쓰는 유닛을 보고 안전한 칸을
골라 준다.

## 소비 관용구 — `Subtract` 는 다른 이야기다

죽음 수에는 두 가지 쓰임이 있고 **섞으면 안 된다.**

| 쓰임 | 하는 일 | 그 유닛이 맵에 있어도 되나 |
| --- | --- | --- |
| **변수** (`Set To`·`Add`) | 레벨·목숨·상태를 담는다 | **안 된다.** 실제 죽음이 값을 망친다 |
| **소비** (`At least` + `Subtract`) | 실제로 죽은 수만큼 보상한다 | **된다.** 오히려 그게 목적이다 |

```
✗ Kill("Current Player", "Men", At least, 1)  →  돈 +25, Preserve
    누적 조건이라 첫 킬 뒤로 매 프레임 돈이 들어온다

✓ Deaths("적", "저글링", At least, 1)
    → Set Deaths("적", "저글링", Subtract, 1);  돈 +25;  Preserve
    죽은 수를 하나씩 깎으며 그만큼만 준다
```

`verify_map.py` 의 검사 10 이 이 구분을 본다 — 변수 쓰임(`Set To`·`Add`)
일 때만 "맵에 놓인 유닛" 을 잡는다. 처음엔 구분 없이 잡아 성한 키우기
맵을 틀렸다고 했다.

## 스위치와 견주면

| | 죽음 수 | 스위치 |
| --- | --- | --- |
| 개수 | 유닛×플레이어 = 아주 많다 | **256개** |
| 값 | 0 ~ 2³²−1 | 켜짐/꺼짐 |
| 범위 | **플레이어마다 따로** | 맵 전체에 하나 |
| 이름 | 유닛 이름 (바꿀 수 있다) | `Switch N` 번호뿐 |

**스위치는 맵 전체에 하나**라 사람마다 다른 상태를 담을 수 없다.
"이 사람이 안내를 봤나" 같은 것은 반드시 죽음 수로 한다 — 스위치로
하면 첫 사람만 걸리고 나머지는 지나간다.
