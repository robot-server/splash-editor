# 랜덤 — 스위치를 이진수 한 자리로 쓴다

출처: 스타 에디터 아카데미
[[예제] 스위치, 데스값을 이용한 랜덤 구현](https://cafe.naver.com/edac/book5095361/76590).

스타 트리거에는 난수가 없다. **`Set Switch` 의 `Randomize` 하나**가
전부다. 그것으로 0~N 을 만든다.

## 원리

`Randomize` 는 스위치를 Set / Cleared 중 하나로 만든다. **이진수 한
자리**다. 자리를 여러 개 모으면 수가 된다.

```
Randomize → Set 이면  데스값 +1     (첫째 자리)
Randomize → Set 이면  데스값 +2     (둘째 자리)
Randomize → Set 이면  데스값 +4     (셋째 자리)
                      → 0~7 중 하나
```

스위치 하나를 **세 번 돌리면** 0~7 이 나온다. 네 번이면 0~15,
다섯 번이면 0~31.

## 방식 1 — 값을 새로 정한다

```
Trigger("Player 1"){
  Conditions: Always();
  Actions:
    Set Switch("Switch 1", randomize);
    Preserve Trigger();
}
Trigger("Player 1"){
  Conditions: Switch("Switch 1", set);
  Actions:
    Set Deaths("Current Player", "Cantina", Add, 1);
    Preserve Trigger();
}
```

이것을 +2, +4 로 세 벌 만들고, 마지막에 데스값에 따라 유닛을 만든다.
**데스값을 다시 0 으로 돌려놓는 것을 잊지 않는다** — 안 그러면 다음
주기의 값에 얹힌다.

### 문제 — 미뤄진다

6가지를 뽑고 싶은데 0~7 이 나오면, **6·7 이 나온 주기는 버리고 다음
주기로 미룬다.** 여기까지는 괜찮다.

**17가지**를 뽑으려면 0~31 을 만들고 17~31 을 버려야 한다 — **거의
절반이 미뤄진다.** 연속으로 미뤄지면 "한참 뒤에야 작동" 하는 일이
잦아진다.

## 방식 2 — 값을 더하고 넘치면 뺀다

미뤄지지 않는다. 데스값을 **버리지 않고 굴린다.**

```
매 주기   데스값 += (0~7 랜덤)
데스값 ≥ 6 이면  데스값 -= 6
```

데스값이 늘 0~5 안에 있게 된다.

### 함정 둘

1. **더하는 범위를 뽑을 범위보다 넓게 잡는다.**
   0~5 를 뽑는데 더하는 값이 0~3 이면, 데스값 1 에서 다음 값은 1~4 뿐
   이라 **0 과 6 이 나올 확률이 0%** 다. 0~7 로 잡아야 고르게 돈다.

2. **빼는 트리거를 두 벌 넣는다.**
   데스값 5 에 +7 이면 12 가 된다. 6 을 빼도 6 이라 **또 6 이상**이다.
   빼는 트리거가 하나뿐이면 다음 주기에야 빠져 **한 주기 늦는다.**
   같은 트리거를 하나 더 두면 한 주기 안에 끝난다.

## 어느 쪽을 쓰나

| | 방식 1 | 방식 2 |
| --- | --- | --- |
| 미뤄짐 | **있다** | 없다 |
| 트리거 수 | 적다 | 조금 많다 |
| 고르게 나오나 | 고르다 | **범위를 넓게 잡아야** 고르다 |
| 쓸 자리 | 가짓수가 2의 거듭제곱에 가까울 때 | **가짓수가 어중간할 때** |

## 두 곳에서 동시에 쓰려면

**스위치와 데스값 칸을 따로 쓴다.** 카페 예제도 마린은 스위치1 +
`Cantina`, 고스트는 스위치2 + `Cave` 로 나눈다.

쓸 수 있는 데스값 칸을 고르는 법은
[death-counts.md](death-counts.md) 에 있다 — **맵에 실제로 나오는
유닛을 변수로 쓰면 안 된다.**
