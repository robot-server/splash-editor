# 미션 브리핑과 게임 중 텍스트

## [트리거/로직 패턴]

- 패턴 이름: 시작 전 순차 안내와 게임 중 상태 안내 분리
- 구현하고자 하는 기능: 임무 목표·조작법을 시작 전에 익히게 하고, 플레이 중에도 필요한 규칙을 다시 확인시킨다.
- 조건(Condition) 및 액션(Action) 구조 체인: Mission Briefing은 조건 분기 없이 지정 플레이어의 액션을 순차 실행한다. `Mission Objectives`에 목표·지속 참조 규칙을 두고, `Text Message`/`Wait`/음성·초상 액션은 필요한 설명 흐름으로 구성한다. 게임 중 위치별 설명은 일반 트리거 조건과 메시지 액션으로 별도 구현한다. [강좌: 미션 브리핑과 스트링](https://cafe.naver.com/edac/book5095361/76453).
- 예외 처리/버그 방지 로직: 플레이 중 상태에 따라 달라지는 분기를 briefing 안에서 기대하지 않는다. 텍스트 액션의 `Always Display` 옵션은 게임 자막 설정이 꺼져 있을 때도 출력되도록 하는 것으로 강좌가 설명한다. 이는 영구 HUD 표시가 아니다. 계속 보아야 하는 규칙은 Mission Objectives처럼 플레이 중 다시 열 수 있는 영역에도 제공하고, 수시 반복 메시지는 재발 조건을 통제한다.

## [에디터 타일/배치 제약사항]

- 지형 간 연결 규칙: 해당 없음. 다만 안내가 지칭하는 비콘/목표/상점 이름을 맵 로케이션 및 시각 표식과 일치시킨다.
- 유닛 길막/동선 보장 규칙: 안내에 적은 상호작용 위치와 실제 트리거 로케이션을 대조하고, 플레이어가 해당 지점에 접근 가능한지 게임에서 확인한다.

표본 빈도나 일반적인 설명 분량을 기준으로 삼지 않는다. 각 규칙의 실제 필요도와 재참조 방법을 기준으로 문구를 배치한다.
