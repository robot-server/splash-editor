# 유닛을 꾸밈으로 쓰기 — Disable 과 Active

출처: 스타 에디터 아카데미
[[팁] Set Doodad State의 Disable 효과](https://cafe.naver.com/edac/book5095361/76525) ·
[[팁] 유닛 스프라이트의 Active 효과](https://cafe.naver.com/edac/book5095361/76540).

유닛을 **움직이지 않는 장식**으로 바꾸는 두 길이 있다. 원래 설치물
타일의 문·트랩용으로 만든 것을 **블리자드가 막아 둔 것을 SCMD2 가
열어 준** 것이라, 유닛마다 결과가 제각각이고 **튕기는 것도 많다.**

| 길 | 어떻게 | 언제 |
| --- | --- | --- |
| **`Set Doodad State` (Disable)** | 트리거 액션 | 게임 중에 바꾼다 |
| **유닛 스프라이트 Active** | 배치할 때 | 처음부터 장식 |

두 길의 결과가 **서로 다르다.** `Set Doodad State` 에서 멀쩡하던
프로토스 건물이 Active 에서는 죄다 고인돌이 된다.

## 먼저 — 맵을 날리는 조합

| | |
| --- | --- |
| **시즈탱크(시즈 모드) · 골리앗 스프라이트를 Active 로** | **에디터가 먹통이 되고, 그 상태로 저장하면 맵을 못 연다** |
| 부가유닛(포탑)이 붙은 유닛 전부 | 같다 |

> 손대기 전에 맵을 복사해 둔다.

## 튕기는 것

| 길 | 튕기는 유닛 |
| --- | --- |
| `Set Doodad State` Disable | **메딕 · 시즈탱크(시즈 모드) · 골리앗 · 시민 · 오버로드 · 인페스티드 커맨드 센터** |
| 스프라이트 Active | **프로브 · 아콘 · 다크 아콘 · 시즈탱크(양쪽) · 골리앗** |

> **투명(깜빡임 포함) 건물은 체력이 깎여 불이나 피가 나면 튕긴다.**
> `Kill Unit` 으로 **한 번에 죽이는 것은 괜찮다.** 장식으로 쓸 거면
> 공격받지 않는 자리에 두거나 무적을 건다.

## 무슨 일이 일어나나

| 말 | 뜻 |
| --- | --- |
| **제어불가** | 명령도, 생산도, 업그레이드도 안 된다. 건물은 클릭하면 언파워드 소리 |
| 투명 | 안 보인다. **드래그로만** 잡힌다 |
| 투명 (깜빡임) | 가끔 아무 프레임이나 깜빡 보인다 (시체 모습이 나오기도) |
| 클로킹 | 클로킹한 것처럼 보인다 |
| 모션 | 어떤 동작을 되풀이한다 |
| **고인돌 생성** | 거는 순간 고인돌이 생긴다. **리마스터 전에는 튕기던 것들** |
| 폭발 소리 | 거는 순간 건물 터지는 소리 |
| 불안정한 방향 | 방향이 마구 바뀐다 |

## 실제로 쓸 만한 것

대부분은 고인돌이라 쓸 데가 없다. **쓸 만한 것만** 추린다.

| 쓰임 | 어떻게 |
| --- | --- |
| **건설 중인 건물 꾸미기** | **테란 건물 스프라이트를 Active** 로 두면 **덜 지어진 모습**이 된다 |
| 저그 건물 장식 | 저그 건물은 Active 로 두면 **제어불가만** 되고 고인돌이 안 생긴다 |
| 크립 밖의 라바 | 라바를 Active 로 두면 **크립 밖에서도 산다** (180도 회전) |
| 인구수만 주는 서플라이 | 서플라이 디팟을 Disable 하면 클로킹으로 보이면서 **인구수는 준다** |
| 공격하는 벙커 | 벙커를 Disable 해도 **안에 든 유닛은 공격한다** |
| 다크 템플러 장식 | Active 로 제어불가 + 180도 회전. 고인돌이 없다 |

> **Active 로 놓은 유닛·건물은 충돌 크기가 없다.** 유닛이 통과한다.
> 길을 막는 장식으로는 못 쓴다.

## 여러 개를 한꺼번에 Active 로

다중 선택한 뒤 속성창의 **`Selected Sprites`** 에서 원하는 것을 골라
`Active / Disabled` 에 체크해야 걸린다. 그냥 체크하면 안 걸린다.

## 우리 CLI 로

```sh
splash-cli sprite set 맵 <번호> --as-sprite off --disabled on -o 새맵
splash-cli sprite place 맵 <번호> <x> <y> --owner P --as-unit -o 새맵
```

`Set Doodad State` 는 트리거 액션이다. **이름에 s 가 붙어 있어도 한
기에만 걸린다** → [../trigger/actions.md](../trigger/actions.md).
