# 타일 색 — 눈으로 갈리는 지형 고르기

`data/tile-colors.json` — 타일 그룹마다 **렌더러로 실제로 그려 재어**
얻은 평균 RGB. `measure_tile_colors.py` 가 만든다.

## 왜 재야 했나

지형 종류 이름만 보고 골랐더니 **화면에서 안 갈렸다.**

- Ice 의 그룹 2 와 3 은 이름이 달라도 색이 `(153,153,15x)` 로 거의
  같다. 바닥과 테두리에 나눠 쓰면 **경계가 안 보인다.**
- 고도만 보고 벽을 골랐더니 **바닥이 벽보다 어두웠다.**

**색은 이름이 아니라 그림에서 온다.** 그래서 잰다.

## 쓰는 법

`scmap.Palette` 가 이 표를 읽어 다섯 몫을 고른다.

| 몫 | 무엇 |
| --- | --- |
| `floor` | 바닥 |
| `path` | 통로 |
| `rim` | 방 테두리 |
| `pad` | 발판 (비콘 자리 등) |
| `wall` | **못 걷는 지형** (물·용암) |

```python
pal = scmap.Palette(cli, tileset_id, rng, "usemap")
print(pal.describe())
pal.fill(cli, "floor", x, y, w, h)
```

고르는 차례가 중요하다.

1. **벽을 먼저 고른다.** 그래야 걷는 몫들을 그보다 밝은 것으로 남길 수 있다.
2. 실측 말뭉치에서 **0.5% 넘게 쓰이는 그룹**만 남긴다.
3. 그룹 0·1 과 1024 이상은 뺀다 (검은 칸, 빈 자리, 두뎃 밑그림).
4. 색을 버킷(`v//12`)으로 묶어 **같은 색을 중복으로 안 쓰게** 한다.
5. 남은 것에서 **서로 가장 먼 네 가지**를 고른다.
6. 인접해 놓일 몫끼리 색이 멀도록 자리를 정한다 (바닥–발판, 바닥–테두리,
   통로–테두리).

## 검은 칸을 쓰지 않는다

못 걷게 막고 싶으면 **검게 뚫지 말고 못 걷는 지형을 깐다.**
실측 유즈맵 485장의 검은 칸 중앙값은 **0.0%** 이고 84%가 1% 미만이다.
