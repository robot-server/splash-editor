# StarCraft 맵 문서

**LLM 이 읽고 바로 쓰기 위한 문서다.** 사람이 읽는 안내서가 아니라,
맵을 만들거나 고칠 때 **짐작을 없애기 위한 사실 창고**다.

## 왜 만드나

이 저장소에서 맵을 만들면서 같은 실수를 되풀이했다. 뿌리는 하나다 —
**게임이 이미 아는 것을 손으로 표를 만들어 짐작했다.**

실제로 겪은 것들:

| 짐작한 것 | 게임이 이미 아는 것 |
| --- | --- |
| 램프 타일 표를 손으로 적음. 네 방향이 같은 세트였고 절반이 없는 타일이었다 | 타일셋 미니타일에 `Ramp` 표시가 있다 (`sc.h`) |
| "Space·Desert·Ice·Twilight 는 램프가 없다" | 넷 다 램프 타일이 있다 (Desert 607개) |
| 두뎃을 아무 지형에나 놓음 | 두뎃마다 `kind` 가 지형 종류 이름과 **같고**, `DoodadPlacibility` 가 놓을 수 있는 그룹을 정확히 말해 준다 |
| "유즈맵은 두뎃을 안 쓴다" (DD2 만 셈) | 두뎃은 저장할 때 지형으로 눌러 담긴다. 타일로 세면 92%가 쓴다 |
| 고도 문턱을 2 로 고정 | 타일셋마다 다르다 (Jungle 1, Badlands 2, Space 는 평지가 1) |

그래서 이 문서 묶음의 규칙은 하나다.

> **짐작해서 적지 않는다. 잰 것만 적는다.**
>
> 잰 값은 여기 적어 둔다 — 매번 다시 재는 것이 더 비효율이다. 대신
> **어떻게 쟀는지를 반드시 함께 적는다**: 어느 스크립트로, 몇 장에서,
> 어떤 자로. 자를 안 적으면 다음에 다른 자로 재고 다른 답을 얻는다
> (고도 기준을 세 번 다르게 잡아 세 번 다른 답을 얻은 적이 있다).
>
> 표가 길거나 기계가 읽어야 하는 것은 `data/*.json` 에 두고 여기서
> 가리킨다. 사람이 판단할 때 필요한 요약은 여기 적는다.

## 어떻게 읽나

| 갈래 | 무엇이 있나 |
| --- | --- |
| [tileset/](tileset/) | 타일셋이 스스로 말해 주는 것 — 지형 종류·고도·램프·두뎃·색 |
| [chk/](chk/) | 맵 파일 구조. 어느 섹션이 무엇을 정하나 |
| [trigger/](trigger/) | 트리거 문법과 실측 관용구 |
| [melee/](melee/) | 밀리맵 — 밸런스·지형·실패 기록 |
| [usemap/](usemap/) | 유즈맵 — 지형 문법·재미 구조·장르 |
| [survey/](survey/) | 전수조사 방법과 결과. 무엇을 몇 장에서 쟀나 |
| [cafe/](cafe/) | 스타 에디터 아카데미(네이버 카페)에서 배운 것 |

## 출처

1. **게임 설치본** — 타일셋(CV5·VF4·VX4·WPE), 두뎃(dddata.bin),
   유닛 표. `splash-cli` 로 읽는다.
2. **scmscx.com** — 실제 맵. 밀리 260장, 유즈 421장을 내려받아 전수로
   떴다. **원본 맵은 이 저장소에 커밋하지 않는다.** 거기서 뽑은 통계만
   남긴다.
3. **스타 에디터 아카데미** (네이버 카페 `edac`) — 사람이 정리한 관용구와
   함정.

## 재는 스크립트

모두 `.agents/skills/starcraft-map/scripts/` 에 있고, 결과는 같은 스킬의
`data/*.json` 에 쓴다.

| 스크립트 | 무엇을 재나 | 결과 |
| --- | --- | --- |
| `measure_terrain_types.py` | 지형 종류 → 타일 그룹·고도 | `terrain-types.json` |
| `measure_tile_colors.py` | 타일 그룹의 실제 색 (렌더러로) | `tile-colors.json` |
| `measure_doodads.py` | 두뎃이 걷기를 막는가 | `doodad-walk.json` |
| `measure_ramps.py` | 램프를 찾아 **걸어서** 검증 | `ramps.json` |
| `classify_genre.py` | 트리거 지문으로 장르 가르기 | `genre-fingerprints.json` |
| `corpus.py` | 실측 분포 읽기 | `corpus.json` |

## 여기에 무엇을 적지 않나

- **사용자의 맵 파일 이름.** 증상·수치·원인만 적는다.
- **원본 맵 파일.** 통계와 방법만 남긴다.
- **재면 되는 수치.** 스크립트와 결과 파일을 가리킨다.
