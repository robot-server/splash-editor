# [트리거/로직 패턴]

## 게임 중 생성된 특정 유닛의 구조체를 찾아 조작

- 패턴 이름: 유닛 번호와 CUnit 인덱스를 구분해 대상 인스턴스 선택
- 구현하고자 하는 기능: 이미 배치된 유닛 또는 트리거가 방금 생성한 유닛 한 마리의 체력·위치·명령 같은 인스턴스 상태를 읽거나 변경한다.
- 조건(Condition) 및 액션(Action) 구조 체인: 사전 배치 유닛은 확정된 CUnit 인덱스를 사용한다. 런타임 생성 유닛은 `Create Unit` 직전에 다음 유닛 구조 주소를 읽고, 생성 후 해당 인스턴스 주소에 작업한다. 버튼으로 스킬을 요청하는 패턴은 해당 유닛 버튼셋에 생산 토큰과 `Current unit is...` 요구사항을 연결하고, 대기열 토큰을 확인한 뒤 스킬 동작을 실행하고 큐에서 제거한다.
- 예외 처리/버그 방지 로직: EUD는 [limits.md](limits.md)의 승인·버전 확인을 먼저 거친다. 같은 유닛 종류가 여러 개면 unit type만으로 대상 인스턴스를 특정할 수 없다. 버튼 요구사항을 생략하면 다른 유닛도 토큰을 만들 수 있으며, 스킬 처리 뒤 대기열을 비우지 않으면 다음 요청과 상태가 섞인다. 요구사항 추가는 버튼셋 용량을 사용하므로 실제 게임에서 선택·사용을 확인한다.

> **먼저 [limits.md](limits.md) 를 읽는다.**

**유닛 번호(type)와 유닛 인덱스(index)는 다르다.**

| | 무엇 |
| --- | --- |
| 유닛 **번호** | 종류. 마린 0, 질럿 65 |
| 유닛 **인덱스** | **그 유닛 한 마리 자체.** 0~1699 |

인덱스마다 **0x150 바이트짜리 구조체**가 있고, 거기에 현재 체력 ·
소유 플레이어 · 바라보는 방향 · 위치 · 내려진 명령 · 남은 공격
쿨타임 · 인스네어 남은 시간 같은 것이 들어 있다.

## 주소 — **0번 다음이 1699번이다**

인덱스가 0에서 1699로 증가할수록 주소는 낮아진다.

| 인덱스 | 시작 주소 |
| ---: | --- |
| 0 | `0x628298` |
| **1699** | `0x59CCA8` |
| 1698 | `0x59CDF8` |
| … | … |
| **1** | `0x628148` |

식으로 적으면:

```
CUnit(n) = 0x59CCA8 + (1699 − n) × 0x150       (0 ≤ n ≤ 1699)
```

카페가 든 다섯 값에 모두 맞는다 — `CUnit(10) = 0x627578`,
`CUnit(1) = 0x628148`. **직접 맞춰 확인했다.**

카페는 "외울 필요 없다" 고 하지만, 식이 정확하므로 **계산해서 쓰면
된다.** eudplib 의 `CUnit()` 함수가 이 일을 한다.

## 내가 만든 유닛의 인덱스를 알려면

| 상황 | 방법 |
| --- | --- |
| 맵에 **미리 배치**한 유닛 | 인덱스가 정해져 있다. 에디터에서 본다 |
| 조건에 맞는 **모든** 유닛 | 유닛 루프를 돌린다 |
| **트리거로 방금 만든** 유닛 | **`0x628438`** |

> **`0x628438` 에는 "다음에 생성될 유닛의 구조 오프셋 주소" 가 들어
> 있다.** 유닛을 만들기 **직전에** 이 값을 읽어 두면, 만들어진 유닛의
> 주소를 그대로 얻는다.

주인공 유닛처럼 게임 도중에 만들어지는 유닛을 다룰 때 이것 말고는
길이 마땅치 않다. 맵에 마린이 여럿이면 유닛 루프로도 못 고른다.

카페 예제는 이것으로 **죽으면 되살아나고 락다운에 안 걸리는 스카웃**을
만든다.

## 대기열 인식 — 버튼을 만드는 관용구

스킬 버튼을 만드는 표준 얼개다.

1. 그 유닛의 **버튼셋에 유닛 생산 버튼**을 하나 만든다 (배럭의 마린
   생산 버튼을 복사해 고치는 것이 편하다).
2. 뽑을 유닛은 **시민** 같은 안 쓰는 유닛으로 한다.
3. **요구사항**을 반드시 건다 — `Current unit is... <그 유닛>`.
   **"무조건 허용" 으로 두지 않는다.**
4. 버튼을 누르면 **생산 대기열에 시민이 올라간다.** 그것을 읽어
   스킬 트리거를 돌린다.
5. 돌린 뒤 **대기열을 비운다.**

버튼 아이콘과 글자는 FireGraft 로 바꾼다
([../tools/editors.md](../tools/editors.md)).

> 요구사항을 걸면 **용량이 넘친다.** 안 쓰는 트랩류 요구사항을 빼서
> 자리를 만든다 — 맵에서 트랩을 쓴다면 다른 데서 확보해야 한다.
