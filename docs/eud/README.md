## 한 줄

EUD 는 **오직 게임 안의 재미를 위해서만** 쓴다. 플레이어 컴퓨터에
해를 끼치거나, 상대를 못 하게 만들거나, 몰래 무언가 하는 데는 쓰지
않는다. 쓰기 전에 **사용자에게 묻는다.**
