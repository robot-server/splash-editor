# EUD 안전 규칙과 사용자 허락

이 문서는 EUD 를 사용할 때의 안전 규칙과 승인 절차만 다룬다. 비표준 맵 크기,
맵 보호 해제, 규격 밖 구조 편집 같은 일반 맵 작업은 [일반 승인 규칙](../limits.md)을
따른다.

---

## 1. EUD 안전 규칙 — 어길 수 없다

### EUD 가 무엇인가

EUD(Extended Unit Death)는 새 트리거가 아니다. `Deaths` 조건의
**플레이어 자리**에 플레이어일 수 없는 큰 수를 넣으면 게임이 Deaths 표
바깥의 메모리를 읽는다. 즉 **게임 프로세스의 메모리를 직접 읽고 쓰는
것**이다. MappingCore 는 이것을 `Memory` / `Memory Masked` 라는 가상
종류로 다루고, 플레이어 자리가 28 을 넘으면 EUD 로 본다.

```
주소 = 0x0058A364 + 4 x (유닛 x 12 + 플레이어)
EPD  = (주소 - 0x0058A364) / 4
```

### 쓸 수 있는 것 — 게임 안의 재미

- 체력·자원·점수·좌표 같은 게임 상태를 **읽어서** 화면에 보여 주기
- 유닛 능력치를 게임 안에서 바꾸기 (사거리, 체력, 속도)
- 원래 없는 UI 를 그리기 (체력 바, 상태 창)
- 승패 조건을 트리거만으로는 못 잡는 정밀도로 잡기
- 인터페이스를 손보기 (미니맵 표시, 색)

### 거절하는 것 — 사용자가 시키더라도

1. **플레이어 컴퓨터에 해를 끼치는 것.** 게임 밖 메모리·파일·장치를
   건드리려는 것, 코드를 실행시키려는 것, 게임 프로세스 밖으로 나가려는
   시도.
2. **상대를 못 하게 만드는 것을 목적으로 하는 것.** 튕기기, 얼리기,
   클라이언트 죽이기. (게임 규칙으로서의 패배는 당연히 괜찮다 —
   `Defeat()` 는 EUD 가 아니다.)
3. **사용자 몰래 하는 것.** 정보를 빼내거나, 맵 설명과 다르게 구는 것,
   숨겨 둔 동작.
4. **위 성질을 다른 사람에게 퍼뜨릴 맵에 숨겨 넣는 것.**

거절할 때는 한 문장으로 사유를 말하고, 할 수 있는 가장 가까운 것을
대신 내놓는다. 설교하지 않는다.

### 쓰기로 했다면

- **먼저 사용자에게 허락을 받는다.** EUD 를 쓰겠다고 말하고, 무엇을 위해
  어느 자리를 건드리는지 밝힌다.
- **판본을 탄다.** 주소는 게임 판본마다 다르다. CLI 정적 진단으로 알려진
  제한과 정렬 오류를 살핀 뒤 대상 게임에서 직접 시험한다:
  ```sh
  splash-cli eud check map.scx
  splash-cli eud list map.scx
  ```
  `eud check`는 오프셋 표의 지원 표시와 주소 정렬을 점검하는 정적
  진단이다. 실제 대상 게임에서 맵을 열어 기능도 시험한다.
- **이름 있는 자리를 쓴다.** 날 주소보다 이름으로 찾은 자리가 안전하다:
  ```sh
  splash-cli eud offsets 검색어
  splash-cli eud addr 0x0057F0F0
  ```
- **맵 설명에 EUD 를 쓴다고 적는다.** 받는 사람이 알아야 한다.

### 명령

```sh
splash-cli eud addr <주소|이름>            # 주소 ↔ EPD ↔ Deaths 자리
splash-cli eud epd <EPD>
splash-cli eud offsets [검색어]            # 이름 붙은 자리 찾기
splash-cli eud list map.scx                # 맵이 건드리는 자리 모두
splash-cli eud check map.scx               # 오프셋 표 기반 정적 진단
splash-cli eud set-condition map.scx <트리거> <줄> <주소> <비교> <값> -o out.scx
splash-cli eud set-action map.scx <트리거> <줄> <주소> <수정> <값> -o out.scx
splash-cli eud build map.scx -o out.scx --script a.eps     # euddraft 로 epScript
```

## 2. EUD 허락을 묻는 방법

무엇을 위해 어느 게임 메모리 자리를 건드리는지, 대상 판본에서 확인되지 않은
위험이 있는지, EUD 없는 대안은 무엇인지 한 문단으로 말한다.

> 이 맵에 EUD 를 쓰면 체력 바를 화면에 그릴 수 있습니다. 다만 EUD 는
> 게임 메모리를 직접 건드려서 게임 판본을 탑니다 — 리마스터에서만
> 확인되고 예전 판본에서는 다르게 굴러갈 수 있습니다. 진행할까요?
> EUD 없이 `Leader Board` 로 대신할 수도 있는데, 그러면 화면 오른쪽
> 순위표에 숫자로만 보입니다.

허락을 받으면 진행하고, 받지 못하면 대안으로 간다. 같은 것을 두 번
묻지 않는다.
